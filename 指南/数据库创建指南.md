# 📊 数据库集合创建指南

## 方式一：在云开发控制台手动创建（推荐）

### 步骤：

1. **打开云开发控制台**
   - 在微信开发者工具中
   - 点击顶部菜单栏的 **"云开发"** 按钮
   - 或者访问：https://console.cloud.tencent.com/tcb

2. **进入数据库页面**
   - 在左侧菜单点击 **"数据库"**

3. **创建集合**
   依次创建以下 5 个集合：

   | 集合名 | 说明 |
   |--------|------|
   | `users` | 用户信息（openid、角色、权限） |
   | `orders` | 订单数据 |
   | `products` | 商品信息 |
   | `customers` | 客户信息 |
   | `receivable` | 赊销记录 |

   **创建方法**：
   - 点击 **"添加集合"** 按钮
   - 输入集合名称（如 `users`）
   - 点击 **"确定"**

4. **设置权限**（测试阶段）
   - 点击每个集合
   - 点击 **"权限设置"**
   - 选择 **"所有用户可读写"**
   - 点击 **"保存"**

### 权限配置示例（生产环境建议）

```json
{
  "read": "auth.openid == doc.openid or doc.role == 'admin'",
  "write": "auth.openid == doc.openid or doc.role == 'admin'"
}
```

## 方式二：通过云函数自动创建

如果手动创建不方便，可以部署一个初始化云函数：

### 1. 创建初始化云函数

在 `cloudfunctions` 目录下创建 `init-db` 文件夹：

```bash
cd /Users/god/Desktop/项目/github/fenghuai-trading/cloudfunctions
mkdir init-db
cd init-db
```

### 2. 创建 package.json

```json
{
  "name": "init-db",
  "version": "1.0.0",
  "description": "初始化数据库集合",
  "main": "index.js",
  "dependencies": {
    "wx-server-sdk": "~2.6.3"
  }
}
```

### 3. 创建 index.js

```javascript
const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });
const db = cloud.database();

exports.main = async (event, context) => {
  const collections = ['users', 'orders', 'products', 'customers', 'receivable'];
  const results = [];
  
  for (const name of collections) {
    try {
      // 尝试添加一条测试数据来创建集合
      await db.collection(name).add({
        data: {
          _created: Date.now(),
          _note: '初始化测试数据'
        }
      });
      results.push({ name, status: 'created' });
    } catch (err) {
      if (err.errMsg && err.errMsg.includes('already exists')) {
        results.push({ name, status: 'exists' });
      } else {
        results.push({ name, status: 'error', error: err.errMsg });
      }
    }
  }
  
  return {
    code: 0,
    message: '数据库初始化完成',
    data: results
  };
};
```

### 4. 上传并调用

1. 在微信开发者工具中，右键 `init-db` 文件夹
2. 选择 **"上传并部署：云端安装依赖"**
3. 部署完成后，在小程序中调用：

```javascript
wx.cloud.callFunction({
  name: 'init-db',
  success: res => {
    console.log('数据库初始化结果:', res.result);
  }
});
```

## 验证集合是否创建成功

在云开发控制台的数据库页面，应该能看到以下 5 个集合：

- ✅ users
- ✅ orders
- ✅ products
- ✅ customers
- ✅ receivable

如果集合列表中出现这些名称，说明创建成功！
