## 常用命令

### 测试相关

```bash
# 运行完整自动化测试（推荐）
./tests/run-full-automation.sh

# 仅运行集成测试
node tests/integrated-test.js

# 仅运行单元测试
node tests/auto-test.js

# 仅运行 UI 测试
node tests/complete-ui-test.js
```

### 云函数相关

```bash
# 检查部署状态
node tests/upload-cloudfunctions.js check-deployed

# 上传未部署的云函数
node tests/upload-cloudfunctions.js upload-failed

# 上传所有云函数
node tests/upload-cloudfunctions.js upload-all

# 上传指定云函数
node tests/upload-cloudfunctions.js upload-specific auth customers orders
```

## 遇到问题？

- **MCP 服务失败**: `pkill -f wechat-devtools-mcp` 后重试
- **云函数上传失败**: 检查微信开发者工具是否登录
- **测试失败**: 查看详细报告 `集成测试报告.json`
