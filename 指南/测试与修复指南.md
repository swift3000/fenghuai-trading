## 🐛 常见问题及解决方案

### 问题 1: "云函数未部署"
**症状**: 控制台显示 "cloud.callFunction:fail error:fail cloud function not found"

**解决方案**:
1. 在微信开发者工具中
2. 右键点击 `cloudfunctions` 文件夹
3. 选择 **"上传并部署：云端安装依赖"**
4. 等待部署完成

### 问题 2: "数据库集合不存在"
**症状**: 控制台显示 "errCode: -502001, errMsg: database set not found"

**解决方案**:
1. 打开云开发控制台
2. 进入"数据库"
3. 手动创建以下集合：
   - `users`
   - `orders`
   - `products`
   - `customers`
   - `receivable`

### 问题 3: "权限不足"
**症状**: 控制台显示 "errCode: -501001, errMsg: permission deny"

**解决方案**:
1. 打开云开发控制台
2. 进入"数据库"
3. 设置每个集合的权限为"所有用户可读写"（测试阶段）
4. 或配置正确的权限规则

### 问题 4: "页面空白"
**症状**: 页面加载后显示空白

**解决方案**:
1. 查看控制台是否有 JavaScript 错误
2. 检查 `onLoad` 是否正确接收参数
3. 检查数据加载逻辑
4. 检查 `setData` 是否正确
