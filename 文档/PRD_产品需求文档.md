## v1.0核心原则（方案B）

### 原则1：极简化登录
**所有账号都绑定微信openid，优先微信一键登录**：
- ✅ 微信一键登录：打开小程序 → 直接进入，2秒完成
- ✅ 管理员帮重置：后台生成临时密码（如AbC@1234），用户首次登录强制修改
- ✅ 离职账号：禁用+解绑微信，数据保留

### 原则2：小程序为主，Web后台极简
- ✅ **所有人用小程序**：下单员、库管、管理员日常操作全在小程序完成
- ✅ **Web后台仅3页**：订单确认、导出Excel、打印送货单，无其他页面
- ✅ 商品管理、客户管理、订单管理全部移到小程序内完成

### 原则3：区域按业务表单划分（不按行政区划）
**区域划分以客户提供的业务表单为准，不按安康市行政区划组织**。区域为业务自定义分类，用于客户分组和报表汇总，与行政归属无关。区域可在小程序内维护（增删改），不强制4级层级。

- 区域示例（按业务实际，可调整）：白河县、汉滨区、旬阳市、汉阴县、岚皋县、平利县、石泉县、紫阳县、宁陕县、镇坪县、外县（镇安/柞水/商南等）
- 区域字段：区域ID、区域名称、排序、状态
- 区域仅作为业务分组标签，不绑定省/市/县行政层级

### 原则4：蓝牙打印（v0.1必做，方案B核心）
**小程序直接连接便携热敏打印机，ESC/POS通用指令集**：
- 芯烨 XP-58IIH（58mm）、XP-80C（80mm）
- 佳博 GP-58MBIII、GP-80250
- 汉印 HM-A300、HM-A350
- 技术方案：微信小程序蓝牙API + ESC/POS指令集，不依赖厂商SDK

## 2. 产品定位

### 2.1 产品愿景
为丰淮商贸的一线下单员、库管和老板提供一套**超轻量、低成本、即开即用**的小程序下单解决方案，全员使用小程序完成日常操作，Web后台仅做订单确认和Excel导出/打印，取代传统纸质单据与手工汇总。

### 2.2 核心价值
1. **全员小程序**：下单、查单、改单、蓝牙打印全在小程序完成，无需电脑。
2. **极简Web后台**：仅3页——订单确认、导出Excel、打印送货单，零学习成本。
3. **蓝牙打印即打即走**：便携热敏打印机现场出单，客户直接签收。
4. **数据实时**：订单状态、汇总报表实时可见。

### 2.3 目标用户
- **下单员（业务员）**：外出拜访客户，现场完成订单录入 + 蓝牙打印送货单。
- **库管**：小程序/Web后台确认订单、导出出库单。
- **管理员（老板/内勤）**：维护商品与客户资料、审核订单、打印/导出汇总。

## 3. 用户画像

### 3.1 下单员
- 年龄 25-45 岁，习惯使用微信小程序进行移动办公。
- 关注点：操作快、不丢单、算钱准、蓝牙打印能直接出单。
- 使用场景：客户门店、仓库、车里、家里（补单）。
- 痛点：纸质单易丢、手工算错、回办公室重复录入、现场无单客户不签收。

### 3.2 库管
- 年龄 30-50 岁，会用微信小程序 + 基础电脑操作。
- 关注点：订单确认快、导出Excel一键搞定、格式直接能用。
- 使用场景：仓库（小程序确认）、办公室电脑前（导出）。
- 痛点：汇总靠手工、备货单要自己整理。

### 3.3 管理员
- 年龄 30-55 岁，具备基础电脑操作能力。
- 关注点：数据准、能对账、好打印、能导出 Excel。
- 使用场景：办公室电脑前。
- 痛点：汇总靠 Excel、打印格式调半天、历史订单难找。

### 4.3 小程序（全员使用）详细需求

#### 4.3.1 登录与首页
- **登录**：微信授权登录 + 账号绑定（首次绑定后自动识别身份）。
- **首页**：展示"今日待出库订单数"、"常用客户"、"快捷录单入口"、"蓝牙打印快捷入口"。
- **底部Tab**：首页、录单、订单、我的（含蓝牙设置/商品管理/客户管理入口）。

#### 4.3.2 录单流程（核心）
1. **选客户**
   - 支持按区域分组浏览、关键字搜索（客户名/拼音/电话）。
   - 常用客户置顶（最多 10 个）。
   - 新增客户入口：录单时可直接新增客户。
2. **选商品**
   - 商品列表支持分类筛选、关键字搜索、SKU 搜索。
   - 展示商品名称、规格、件价、零价。
   - 新增商品入口：录单时可直接新增商品。
3. **填写数量**
   - 双轨录入：**件数 + 零数**（件为大单位，零为小单位，如件=24 瓶，零=1 瓶）。
   - 实时计算金额：`件数 × 件价 + 零数 × 零价`。
   - 支持快速加减按钮 + 直接输入。
4. **订单操作**
   - 支持多行商品录入，自动合计。
   - 支持"保存草稿"、"提交订单"、"复制订单（基于历史订单）"。
   - 支持"备注"字段（如到货时间、特殊要求）。
   - **提交后一键蓝牙打印**：订单提交成功后弹窗询问「是否立即打印送货单？」。

#### 4.3.3 订单查看与管理
- 订单列表：按时间倒序，显示客户名、金额、状态、颜色标识。
- 支持按状态筛选（草稿/已提交/已确认/已取消）。
- 支持按客户/区域/下单员筛选。
- 订单详情：商品明细、金额、时间、操作人。
- 操作：编辑订单（改后状态回退已提交）、删除订单（二次确认）、复制订单、**蓝牙打印送货单**。

#### 4.3.4 商品管理 & 客户管理（小程序内）
- **商品管理**：
  - 列表：SKU、商品名、规格、件价、零价、分类、状态（启用/停用）。
  - 操作：新增、编辑、停用/启用、搜索、分类筛选。
  - 批量初始化：支持一次性导入 Excel（管理员）。
- **客户管理**：
  - 列表：客户编号、名称、联系人、电话、区域、地址。
  - 操作：新增、编辑、删除、搜索、按区域筛选。
  - 批量初始化：支持一次性导入 Excel（管理员）。

#### 4.3.5 蓝牙打印（v1.0必做，方案B核心）

> 便携热敏打印机现场出单，客户直接签收。采用 ESC/POS 通用指令集，兼容主流品牌。

**功能清单**：
1. **搜索与配对打印机**
   - 我的 → 蓝牙打印设置 → 搜索附近蓝牙设备
   - 展示设备列表：设备名、MAC地址、信号强度
   - 点击配对 → 输入PIN码（默认0000/1234）→ 配对成功
   - 支持"设为默认打印机"，下次自动连接

2. **打印送货单（58mm/80mm自适应）**
   - 订单详情页 → 点击「蓝牙打印」→ 选择打印机 → 打印
   - 支持批量打印：订单列表勾选多张 → 批量打印
   - 打印内容：
     - 头部：门店名称「丰淮商贸」、订单号、日期时间
     - 客户信息：客户名、联系人、电话、地址
     - 商品明细（表格）：序号、商品名、规格、数量、单价、金额
     - 合计：大写金额 + 小写金额
     - 尾部：备注、下单员、签收栏（客户签字______）、「感谢惠顾」

3. **兼容打印机型号（ESC/POS指令集）**

   | 品牌 | 推荐型号 | 纸宽 | 说明 |
   |------|---------|------|------|
   | 芯烨（Xprinter） | **XP-58IIH** | 58mm | 经典便携款，性价比高，首推 |
   | 芯烨（Xprinter） | XP-80C | 80mm | 宽幅款，字大更清晰 |
   | 佳博（Gprinter） | GP-58MBIII | 58mm | 兼容ESC/POS，稳定 |
   | 佳博（Gprinter） | GP-80250 | 80mm | 80mm便携款 |
   | 汉印（HPRT） | HM-A300 | 58mm | 便携随身，待机长 |
   | 汉印（HPRT） | HM-A350 | 80mm | 升级款，支持标签 |

4. **技术规格**
   - 指令集：**ESC/POS**（通用标准，99%热敏打印机兼容）
   - 连接方式：蓝牙 2.0/4.0 BLE（微信小程序蓝牙API）
   - 打印纸宽：58mm / 80mm 自适应检测
   - 编码：GBK/UTF-8 中文支持
   - 支持二维码打印（订单号转二维码，扫码查单）
   - 支持切刀指令（部分机型自动切纸）

5. **异常处理**
   - 连接失败：提示「请检查打印机是否开启并靠近」，3秒后自动重试
   - 缺纸：提示「打印机缺纸，请补纸后重试」
   - 打印内容乱码：自动切换GBK/UTF-8编码重打

#### 4.3.6 我的 & 设置
- 个人信息：姓名、角色、手机号。
- 蓝牙打印设置：搜索设备、配对、设为默认、测试打印。
- 商品管理入口（管理员/下单员可见）。
- 客户管理入口（管理员/下单员可见）。
- 导出中心：商品汇总Excel、客户汇总Excel、出库单Excel。

### 4.4 极简Web后台详细需求（仅3页）

> 方案B核心：Web后台砍到只剩3页，无仪表盘、无图表、无商品/客户/用户管理页面。
> 登录后左侧菜单栏仅3项：订单确认、导出中心、打印送货单。

#### 4.4.0 登录
- 账号密码登录，仅库管/管理员角色可登录。
- 登录成功后直接跳转「订单确认」页。

#### 4.4.1 第1页：订单确认
- **功能**：库管逐张或批量确认今日订单，确认后订单变蓝（已确认）。
- **页面布局**：
  - 顶部筛选：日期（默认今日）、状态（默认：已提交）、区域、下单员。
  - 订单列表（表格，按下单时间倒序）：
    | 列 | 说明 |
    |----|------|
    | 复选框 | 支持批量勾选 |
    | 订单号 | 点击可展开详情 |
    | 下单时间 | YYYY-MM-DD HH:mm |
    | 客户 | 客户名称 + 区域 |
    | 下单员 | 姓名 |
    | 金额 | 合计金额 |
    | 状态 | 颜色标签：草稿灰/已提交橙/**已确认蓝**/已取消红/已完成绿 |
    | 操作 | 「确认」按钮（仅已提交状态可见） |
  - 底部操作栏：
    - 「批量确认」按钮（选中多张已提交订单时亮起）
    - 「16:00自动已通过」提示文案
- **核心逻辑**：
  - 单张确认：点击「确认」→ 状态变蓝（#409EFF）→ 从待确认列表移除。
  - 批量确认：勾选多张 → 点击「批量确认」→ 全部变蓝。
  - 16:00 自动流转：定时任务每天16:00将所有未确认的「已提交」订单→「已确认」。
  - 订单颜色方案：
    - 草稿：灰色 #909399
    - 已提交（待确认）：橙色 #E6A23C
    - **已确认（库管已确认）：蓝色 #409EFF**
    - 已完成：深绿 #008000
    - 已取消：红色 #F56C6C

#### 4.4.2 第2页：导出中心（3种Excel）
- **功能**：一键导出3种标准格式Excel，无需配置。
- **页面布局**：
  - 顶部：时间筛选（日/月/自定义时间段）+ 区域 + 下单员。
  - 中间：3个大卡片按钮（并排展示）。
  - 底部：最近导出记录（文件名、时间、大小、下载链接）。

**3种导出格式**：

| 序号 | 导出项 | 说明 | Excel格式要求 |
|------|--------|------|--------------|
| **1** | **商品汇总表** | 按商品维度汇总销量与金额 | 字段：SKU、商品名、规格、件数合计、零数合计、金额合计、订单数。按金额倒序。 |
| **2** | **客户汇总表（外县台账式）** | 参照「2025收款台账起始12.xlsx」外县表单样式，导出后可直接复制粘贴到台账 | 字段（顺序必须一致）：编号、时间、区域、客户、商品、单位、数量、单价、金额、备注。按客户分组，客户间空行分隔，含金额合计行。 |
| **3** | **出库单（不含价格）** | 库管备货用，不含价格，按客户分组 | 字段：编号、时间、区域、客户、商品、单位、数量、备注。不含价格。每家客户一个Sheet或同Sheet内分组。 |

- **导出操作**：
  - 点击对应卡片 → 弹窗确认筛选条件 → 生成Excel → 自动下载。
  - 支持"导出后发送到微信"（可选，调用企业微信/文件传输助手）。

#### 4.4.3 第3页：打印送货单（浏览器打印）
- **功能**：办公室电脑端批量打印送货单（针式/A4打印），给客户签收。
- **页面布局**：
  - 顶部筛选：日期（默认今日）、状态（默认：已确认）、区域、客户、下单员。
  - 订单列表（带复选框）：订单号、客户、金额、状态、打印次数。
  - 右侧：预览区域（选中订单后实时预览送货单格式）。

## 5. 非功能需求

### 5.1 性能
- 小程序页面加载 < 2s（正常网络）。
- 录单页面操作响应 < 100ms。
- Web后台导出Excel < 3s（万级订单内）。
- 蓝牙打印连接 < 2s，单张打印 < 5s。

### 5.2 可用性
- 系统可用率 ≥ 99.5%（工作时段 8:00-20:00）。
- 支持每日自动备份数据库。
- 关键操作保留审计日志 ≥ 1 年。

### 5.3 安全
- 所有接口 HTTPS 加密。
- 用户密码加密存储（bcrypt）。
- 权限校验（RBAC），越权访问返回 403。
- 防刷与防重放（Token + 时间戳）。

### 5.4 兼容性
- 小程序：微信 7.0+，iOS 10+，Android 7.0+。
- 极简Web后台：Chrome、Edge、Safari 最新两个主版本。
- 蓝牙打印机：ESC/POS指令集，芯烨/佳博/汉印等主流品牌58mm/80mm便携热敏。
- 针式打印机：EPSON LQ系列、映美FP系列等主流品牌（浏览器原生打印）。

### 5.5 可维护性
- 代码分层、模块化。
- 提供部署与操作手册。
- 蓝牙打印适配层抽象，后续新增机型无需改核心逻辑。

## 6. 数据模型（核心）

### 6.1 核心实体

**用户 User**
- id、username、password_hash、name、role(admin/orderer/warehouse)、status、created_at、openid

**客户 Customer**
- id、code、name、contact、phone、region、address、tags[]、created_at

**商品 Product**
- id、sku、name、spec、unit_piece、unit_piece_qty、unit_zero、price_piece、price_zero、category、status、updated_at

**订单 Order**
- id、order_no、customer_id、user_id(下单员)、status、total_amount、remark、
  **warehouse_confirmed(库管是否确认)、confirmed_by(确认人ID)、confirmed_at(确认时间)**、
  created_at、updated_at

**订单明细 OrderItem**
- id、order_id、product_id、product_snapshot(JSON)、piece_qty、zero_qty、price_piece、price_zero、amount

**商品快照 ProductSnapshot**
- {sku, name, spec, price_piece, price_zero, unit_piece_qty}

**状态流转记录 OrderStatusLog**
- id、order_id、from_status、to_status、operator_id、remark、created_at

**蓝牙设备 PrinterDevice（方案B新增）**
- id、user_id、device_name、mac_address、paper_width(58/80)、is_default、created_at

### 6.2 订单状态机

```
草稿(DRAFT) → 已提交(SUBMITTED) → 已确认(CONFIRMED) → 已完成(DONE)
     ↓              ↓                    ↑
 已取消(CANCELED) ←──┘            库管确认 / 16:00自动通过
```

**状态颜色方案**：
- 草稿(DRAFT)：灰色 #909399
- 已提交(SUBMITTED)：橙色 #E6A23C（待库管确认）
- **已确认(CONFIRMED)**：蓝色 #409EFF（库管已确认/16:00自动通过）
- 已完成(DONE)：深绿 #008000
- 已取消(CANCELED)：红色 #F56C6C

### 6.3 关键约束
- 订单号全局唯一，规则：`YYYYMMDD + 4 位序号`。
- 同一订单明细商品 SKU 唯一。
- 快照在"提交订单"时生成并不可变。

## 7. 交互设计要点

### 7.1 小程序主要页面
1. 首页（今日概览 + 快捷录单 + 蓝牙打印入口）
2. 客户选择页（区域分组 + 搜索 + 新增客户）
3. 录单页（商品多选 + 件零双轨 + 实时计价 + 一键打印）
4. 订单列表（筛选 + 批量打印）
5. 订单详情（编辑/删除/复制/蓝牙打印）
6. 商品管理（增删改/导入）
7. 客户管理（增删改/导入）
8. 蓝牙打印设置（搜索/配对/默认/测试打印）
9. 登录页

### 7.2 极简Web后台主要页面（仅3页）
1. **订单确认**：筛选 + 列表 + 单张/批量确认
2. **导出中心**：3种Excel导出大卡片 + 最近记录
3. **打印送货单**：筛选 + 勾选 + 预览 + 浏览器打印

### 7.3 关键交互细节
- **件零联动**：件数变化时自动换算零数（可手动覆盖）；零数变化反向扣减件数。

- **操作反馈**：保存/提交成功 Toast，失败带错误原因。
- **蓝牙打印流程**：提交订单 → 弹窗「是否打印送货单？」→ 是 → 自动连接默认打印机 → 打印中动画 → 完成提示。

## 8. 技术选型

### 8.1 总体架构

```
┌─────────────────┐     HTTPS      ┌─────────────────┐
│  微信小程序      │ ◀────────────▶ │                 │
│  （原生/uni-app） │  蓝牙打印      │   Nginx 反向    │
│                │◀───ESC/POS───▶ │   代理/负载均衡 │
└─────────────────┘ 便携热敏打印机  └────────┬────────┘
                                              │
┌─────────────────┐     HTTPS                │
│ 极简Web后台（3页）│ ◀────────────▶           │
│  （Vue3/React）  │                          ▼
└─────────────────┘                 ┌─────────────────┐
                                    │   API 服务      │
                                    │  （Node/NestJS） │
                                    └────────┬────────┘
                                             │
                                    ┌────────▼────────┐
                                    │   数据库 MySQL   │
                                    └─────────────────┘
```

### 8.2 前端
- **小程序**：**原生微信小程序 + TypeScript**（蓝牙API兼容性最好）或 **uni-app + Vue3**（一套代码多端）。
- **极简Web后台**：**Vue 3 + Vite + Element Plus**（仅3页，轻量化）。
- **无ECharts**：方案B砍掉仪表盘图表，不引入图表库。

### 8.3 后端
- 语言/框架：**Node.js + NestJS**（TypeScript全栈，降低协作成本）。
- ORM：Prisma。
- 认证：JWT（Web后台），微信 openid + 绑定（小程序）。
- 存储：MySQL 8.0，Redis（缓存 + 去重）。

### 8.4 其他
- Excel导出：**exceljs**（Node.js生态，支持复杂格式）。
- 浏览器打印：`window.print()` + CSS `@media print` 控制分页/纸张。
- **蓝牙打印**：微信小程序 `wx.createBLEConnection` + ESC/POS 指令字节流（GBK编码中文）。
- 部署：Docker + Docker Compose，Nginx 反向代理。

### 8.5 选型说明
- 方案B优先选**最轻量、最少依赖**的技术栈，压缩开发和运维成本。
- 蓝牙打印采用原生小程序API，避免跨端框架兼容性问题。
