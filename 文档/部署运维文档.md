## 1. 系统概述与极简原则

### 1.1 系统组成

本系统由以下**两终端 + 一Serverless后端**组成：

| 模块 | 载体 | 形式 | 数量 |
|------|------|------|------|
| 微信小程序端 | 微信 App | 原生小程序代码包 | 1 个 |
| Web 管理后台 | 浏览器 | 单个静态 index.html（含内联 CSS/JS） | 1 份 |
| 后端服务 | 微信云开发（CloudBase） | 8 个云函数 + 6 个数据库集合 + 静态托管 | 1 套环境 |

### 1.2 极简部署原则

**全部 Serverless，零服务器运维**：
- ❌ 无 Linux 服务器购买/续费
- ❌ 无 Docker 容器、无 Nginx 反向代理
- ❌ 无开发/测试/预发布 三套环境（极简版仅 1 套生产环境）
- ❌ 无 CI/CD 流水线
- ✅ 40 分钟完成一次完整部署

## 3. 后端部署：云开发（云函数 + 数据库）

### 3.1 初始化云开发环境

1. 打开「微信开发者工具」。
2. 导入项目：项目目录指向 `miniprogram/`（或 `miniapp/` 小程序根目录），AppID 填 2.1 #1。
3. 点顶部工具栏「☁ 云开发」→ 弹出云开发控制台。
4. 第一次会引导创建环境，命名 `fenghuai-prod`，计费方式选 **按量付费**。
5. 等待环境初始化 1-3 分钟，直到状态为可用。
6. 复制环境 ID（形如 `fenghuai-prod-3gxxxxx`）→ 填到 2.2 表格。

### 4.3 提交审核与发布

## 5. Web 管理后台部署（两种方案，任选其一）

> 🎯 Web 后台只有 1 个单文件 `index.html`（含内联 CSS + JS + 唯一外部依赖：SheetJS xlsx CDN）。零构建，无 node_modules。

### 5.1 部署前：把 ENV_ID 写入 index.html

打开 Web 后台源码目录中的 `index.html`，找到顶部约第 10 行位置：

```html
<script>
  // ============ 生产环境配置（仅改这里即可） ============
  const ENV_ID = 'fenghuai-prod-xxxxx';   // ← 改成你的云开发环境 ID
  // ============ 其他配置 ==================================
  const CDN_XLSX = 'https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js';
</script>
```

保存文件。

### 5.2 方案 A：云开发静态托管（推荐，最快）

1. 云开发控制台 → 静态网站托管 → 开通（按量计费，免费额度覆盖）。
2. 根目录右键上传文件 → 选 `index.html`。
3. 等待 10 秒 → 访问：
   > `https://你的静态托管域名/admin/index.html` 或根目录 `/index.html`。
4. 正常显示登录页 → 用 3.5 创建的 admin/Admin@2026 登录即可。

**优点**：与云函数/数据库同域，调用云函数走 `tcb.init()` 同源，免 CORS、免 HTTP API 签名。

### 5.3 方案 B：上传到对象存储 CDN（腾讯云 COS / 阿里云 OSS / 七牛等）

以腾讯云 COS 为例：
1. 登录 [腾讯云 COS 控制台](https://console.cloud.tencent.com/cos5) → 创建存储桶（北京/上海，公有读私有写）。
2. 存储桶 → 文件列表 → 上传文件 → 选 `index.html`。
3. 存储桶 → 基础配置 → 静态网站 → 开启，默认文档填 `index.html`。
4. 拿到访问域名，例如：
   > `https://fenghuai-admin-123456.cos-website.ap-beijing.myqcloud.com/`

> ⚠️ 注意：**跨域问题**。不同域直接调云函数需通过 HTTP API + 签名（略复杂）。推荐：
> - 把 Web 后台部署在云开发静态托管同源 → 方案 A；
> - 或自定义域名 CNAME 到静态托管 + 在云开发配置自定义域名。

## 6. 数据备份与恢复（最简版）

### 6.1 每日自动备份（免费额度足够）

利用云开发自带的「数据库 → 数据导入导出」功能 + 云函数定时触发：

**步骤（10 分钟设置一次）**：
1. 云开发控制台 → 云函数 → `system-config` 中，新建一个 action（或新建第 9 个函数 `db-backup`）：
2. 逻辑：遍历 6 个集合 → `db.collection().get()` 全部拉取 → JSON → 上传到云存储路径 `backups/YYYYMMDD/集合名.json`。
3. 云开发控制台 → 云函数 → 触发器 → 新建定时触发器：
   - Cron 表达式：`0 0 2 * * * *`（每天凌晨 02:00 执行）
   - 关联函数：`db-backup`
4. 云存储 → 设置生命周期：`backups/` 前缀 31 天自动过期删除（防空间溢出）。

### 6.2 手动一键导出（临时备份）

云开发控制台 → 数据库 → 某集合 → 「更多 → 导出」→ 格式选 JSON/CSV，立即下载。建议每周手动导出一次打包压缩存百度网盘。

### 6.3 恢复

云开发控制台 → 数据库 → 目标集合 → 「更多 → 导入」→ 选 JSON 文件 → 确认。简单、无需写脚本。

## 8. 故障排查速查手册

### 8.1 小程序端

| 问题 | 可能原因 | 处理方法 |
|------|----------|----------|
| 打开小程序白屏 | 网络、AppID 错、代码包上传失败 | 重传代码包；检查 AppID |
| 登录失败：openid 未绑定 | 管理员没把该用户 wx_openid 填到 users 表 | admin 后台 → 用户编辑 → 填入 openid 或让该用户首次登录后台绑定 |
| 商品/客户列表为空 | 集合权限设置过严 | 云开发控制台 → 数据库 → 权限改：所有用户可读 |
| 提交订单失败：order_no 冲突 | 并发下单日单量超 9999 概率极低；偶发则重试 3 次 | 云函数内已做重试，一般不暴露 |
| 订单金额与预期不符 | 93 可调价 SKU 临时改价 / 客户可调价 / 快照数据不一致 | 查订单详情 → items_snapshot 实际存了啥 |

### 8.2 Web 后台端

| 问题 | 可能原因 | 处理方法 |
|------|----------|----------|
| 登录页报 500 | 云函数 `auth-login` 未部署或代码异常 | 云函数日志看具体报错 |
| 登录提示用户名或密码错误 | 3.5 没初始化 admin；或密码不对 | 重置密码：user-write 云函数 `update` 传新 password |
| 订单列表空白 | `data-query` 函数未部署；或 orders 没数据 | 先创建几笔订单验证 |
| 导出 Excel 按钮没反应 | SheetJS CDN 网络不通；浏览器控制台 404 | 把 xlsx.full.min.js 内联到 index.html（文件会变大到 ~1.2MB，可接受） |
| 打印预览没样式 | 浏览器禁用了背景图形；或 @page size 被驱动覆盖 | 打印对话框 → 更多设置 → 勾选"背景图形"；缩放 100% |
| 跨域（COS/OSS 部署时）调云函数失败 | HTTP API 未授权 | 切到云开发静态托管部署 |

### 8.3 蓝牙打印

| 问题 | 可能原因 | 处理方法 |
|------|----------|----------|
| 找不到打印机 | 手机蓝牙/定位权限未给；打印机没开机或没电 | 检查：设置 → 蓝牙开 → 定位开 → 小程序权限全部允许 |
| 打印机已配对但打印乱码 | 机型非 ESC/POS 指令集；字符编码不对 | 买附录 C 推荐三款机型（芯烨/佳博/美团），均标准 |
| 打印一半中断 | 分包发送间隔过短；信号弱 | 代码中 INTERVAL 从 50ms 调到 80ms；重连再打 |
| 二维码扫描不出 | ESC/POS 型号不标准；字节指令写错 | 按 TDD §8.5 字节指令模板重写；或改用 Canvas 生成图片打印 |

### 8.4 云函数 / 数据库

| 问题 | 可能原因 | 处理方法 |
|------|----------|----------|
| 云函数调用失败：-501000 无权限 | 云函数未部署；或小程序未绑定当前环境 | 云环境 ID 检查；重新上传函数 |
| 数据库查询超时 | orders/order_items 表大 + 缺索引 | 对照 3.2 章节检查所有字段索引，特别是 (network_time, status) 组合索引 |
| 云存储上传失败 | 容量超限；权限设置 | 云存储免费额度 5GB，清理历史备份；设置生命周期 |

## 9. 升级与回滚

### 9.1 小程序端版本升级

1. 修改代码 → 开发者工具「上传」新版本号。
2. 小程序后台 → 版本管理 → 提交审核 → 通过后发布。
3. 用户侧：微信自动更新（冷启动时更新），无需手动下载。

### 9.2 Web 后台升级

1. 改完本地 `index.html`。
2. 静态托管 / COS → 覆盖上传同名文件 → 刷新 CDN 缓存。
3. 用户侧：Ctrl+F5 强刷浏览器即可。零停机发布。

### 9.3 云函数升级

1. 改完本地云函数目录代码。
2. 开发者工具 → 云函数文件夹右键 → 「上传并部署：云端安装依赖」。
3. 新版本对新请求立即生效（Serverless 冷启动新实例），无需停服务。

### 9.4 回滚

| 模块 | 回滚方法 |
|------|----------|
| 小程序 | 小程序后台 → 版本管理 → 历史版本 → "回滚"（审核通过的版本都可一键回滚） |
| Web 后台 | `index.html` 上一版本另存了 `index_v1.html` → 直接改回文件；或 COS 历史版本还原 |
| 云函数 | 云开发控制台 → 云函数 → 版本 → 选历史版本 → "设为 $LATEST" |
| 数据库 | 6.1 的 backups 目录 JSON → 云开发导入恢复 |
