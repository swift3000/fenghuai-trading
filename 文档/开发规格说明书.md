## 一、全局设计规范

### 1.1 主题色

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色（绿） | `#06AD56` / `var(--green)` | 主按钮、选中态、成功 |
| 强调色（橙） | `#FF8A2B` / `var(--orange)` | 收款、导出、新增 |
| 危险色（红） | `#FF3B30` / `var(--red)` | 删除、退出 |
| 信息色（蓝） | `#1989FA` | 链接、信息 |
| 文字主色 | `var(--text)` | 正文 |
| 文字次级 | `var(--text-2)` | 次要说明 |
| 文字弱化 | `var(--text-3)` | 弱提示 |
| 背景 | `#F5F6F8` / `#F2F3F5` | 页面背景 |
| 卡片 | `#FFFFFF` | 卡片背景 |

### 1.2 全局字号缩放（适老化）

- CSS 变量 `--font-scale`（rpx 体系），默认 **90%**，范围 **70%–130%**。
- 所有字号用 `calc(Npx * var(--font-scale))` 包裹。
- 入口：状态栏「字」按钮 + 「我的」页「字体大小」。
- 持久化：`users.fontScale`。

### 1.3 通用组件

| 组件 | 规格 |
|------|------|
| 卡片 `.card` | 白底、圆角 `var(--radius)`、阴影 `var(--shadow)` |
| 主按钮 `.btn.primary` | 绿底白字、圆角、加粗 |
| 区块标题 `.sec-title` | 15px、加粗、左侧绿色竖条 |
| 表单行 `.mf-row` | label 上、input 下，间距 15px |

## 三、各页面开发规格

### 3.1 登录页（pages/login/login）

**页面结构**：
```
┌─────────────────────────┐
│        丰淮商贸          │
│      让采购更简单        │
│  👑 首次启动：您将成为首位管理员 │
│  ┌───────────────────┐  │
│  │ 📝 下单员          │  │
│  │ 📦 分拣员          │  │
│  │    库管            │  │
│  │ 👑 管理员          │  │
│  └───────────────────┘  │
│  [ 微信一键登录 ]        │
└─────────────────────────┘
```

**规格**：
- 角色列表：4 项（下单员/分拣员/库管/管理员），点击高亮选中。
- 首次启动无管理员时显示「👑 首次启动：您将成为首位管理员」横幅。
- 底部按钮「微信一键登录」：绿底白字，点击后调 `auth.login`。
- 登录成功 → `wx.switchTab` 到首页。

**API**：`auth.login`（入参 role，返回 userInfo）。

### 3.3 订单列表页（pages/orders/orders）

### 3.4 新建订单页（pages/new-order/new-order）

**页面结构**：
```
┌─────────────────────────┐
│ [请选择客户 ▾]           │
│ ┌─────────────────────┐  │
│ │ 🤖 智能录入（文字/语音） │  │
│ └─────────────────────┘  │
│ ┌─────────────────────┐  │
│ │ 商品明细列表          │  │
│ │ 名称 规格 件 包 单价 金额 │  │
│ └─────────────────────┘  │
│ [+ 添加商品]             │
│ 合计：¥0.00             │
│ [ 保存订单 ]             │
└─────────────────────────┘
```

**规格**：
- 选客户：点击打开客户选择弹窗，支持搜索、常用客户置顶。
- 选客户自动带出上次订单商品（标「预填」徽标）。
- 智能录入按钮：打开智能录入弹窗（文字/语音）。
- 商品明细：每行含名称/规格/件数/包数/单价/金额，可改价（仅当前订单）。
- 数量默认 0；输入框加大（适老化）。
- 合计实时计算；0 元订单拦截。
- 保存订单 → 调 `orders.create`。

**API**：`orders.create`、`smart.match`、`smart.transcribe`。

### 3.8 赊销页（pages/receivable/receivable）

**三栏 Tab**：📋客户台账 / 📌未结清 / ✅已结清。

**客户台账**：以客户为单位显示总账（应收总额/已收/未结清），金额守恒：应收 = 已收 + 未结清。

**独立按钮**：「✅ 收款确认」（打开库管确认工作台）。

**API**：`receivable.dashboard`、`receivable.collect`、`receivable.confirm`。

### 3.9 分拣出库页（pages/outbound/outbound）

**两段切换**：①分拣段（待分拣/已分拣）；②出库段（待出库/已出库）。

**分拣段**：待分拣 → 已分拣，一键完成（`sort:task`）。

**出库段**：待出库(已分拣) → 已出库，库管一步确认（`warehouse:confirm`），可录入物流件型（大/中/小件）。

**API**：`orders.updateStatus`。

## 四、智能录入弹窗规格

**入口**：首页智能录入卡片 + 新建订单页智能录入按钮。

**结构**：
```
┌─────────────────────────┐
│ [文字录入] [语音录入]     │
│ ┌─────────────────────┐  │
│ │ 输入/粘贴文本          │  │
│ └─────────────────────┘  │
│ [🔍 智能解析]            │
│ ┌─────────────────────┐  │
│ │ 解析结果预览           │  │
│ │ 客户+商品明细          │  │
│ └─────────────────────┘  │
│ [确认生成订单]           │
└─────────────────────────┘
```

**文字录入**：textarea 粘贴/输入自然语言。

**语音录入**：麦克风按钮录音 → 阿里 ASR 转文字（未配置时降级）。

**智能解析**：调 `smart.match`，模糊匹配商品/客户，多结果弹选择列表，智能记忆上次选择。

**API**：`smart.match`、`smart.transcribe`。
