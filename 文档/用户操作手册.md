# 丰淮商贸采购下单助手 — 用户操作手册

> **文档版本**：MVP v1.0（2026-08-05 定稿，最终功能范围）
> **编写日期**：2026-07-30
> **最后更新**：2026-08-04
> **状态**：已定稿
> **适用对象**：下单员、分拣员、库管、管理员
> **终端**：微信小程序（全员使用，无 Web 后台）
> **MVP 口径**：本文档已按 MVP（v1.0，2026-08-05）修订，MVP 为最终功能范围，无二期增强；功能清单以《小程序 MVP 落地计划与技术架构》为准。
> **工期**：约 33 人天（MVP 生产化）

## 0. 角色一览

| 角色 | 英文标识 | 典型成员 | 核心职责 |
|------|---------|---------|---------|
| 下单员 | orderer | 张经理等业务员 | 拜访客户现场录单、改单、删单、登记收款、打印送货单 |
| 分拣员 | sorter | 周分拣等理货员 | 对照订单一键分拣（待分拣→已分拣）、填分拣备注、登记收款（驳回为遗留状态，二期规划，当前不触发） |
| 库管 | warehouse | 李库管 | 出库确认（待出库→已出库，一步）、确认收款、导出出库单 |
| 管理员 | admin | 王老板/内勤 | 维护商品/客户/用户、全流程可操作、赊销对账 |

> **1.0 原则**：全员小程序，无 Web 后台；**下单/改单/删单权限给所有人**（4 角色均可，含订单内改价）；分拣员只读与库管价格脱敏规则已取消，全员可见并操作价格。

## 第一部分：登录与首页

### 1. 登录

1. 在微信中搜索「丰淮商贸采购下单助手」或扫描小程序码。
2. 首次打开自动调用微信授权登录，点「允许」。
3. 若该微信号未绑定系统账号，请联系管理员在「用户管理」中绑定后重新登录。
4. 登录后按角色自动跳转默认页：
   - 分拣员 → 分拣出库页（分拣段「待分拣」Tab 默认）
   - 库管 → 分拣出库页（出库段「待出库」Tab 默认）
   - 下单员/管理员 → 首页

### 2. 首页（我的工作台）

- 顶部状态卡：**今日订单 / 今日金额** 两个统计项。
- 下单员首页顶部红条：今日有被驳回（遗留状态，二期规划，当前 MVP 不触发）的订单时显示「您有 X 笔被驳回的订单，请点击查看修改」。
- 展示：今日待出库订单数、常用客户、快捷录单入口、蓝牙打印快捷入口。
- **智能录入入口卡片**：首页中部「🗣 智能录入」卡片，支持文字/语音快速下单（见第二部分补充）。

### 3. 底部 Tab 栏（全角色统一 5 个）

全角色可见同一套 5 个 Tab：**📋首页 / 📦订单 / 💰赊销 / 🔍分拣出库 / 👤我的**（原「分拣」「库管」两个 Tab 已合并为「分拣出库」一个，符合微信 tabBar 上限 5 个）。

- 若某角色被管理员关闭 `receivable:view` / `sort:task` / `warehouse:confirm` 等查看/操作权限，对应 Tab 运行时自动隐藏（1.0 开放权限模型）。
- 报表入口仍在「我的 → 报表统计」，不单独占 Tab。

> 💰「赊销」Tab **所有角色可见**，见第五部分。

### 4. 「我的」页面入口（按角色显示）

- 管理员：蓝牙打印设置 / 商品管理（全角色 CRUD）/ 客户管理（全角色 CRUD）/ 报表统计/ 分拣出库 / **用户管理** / **系统设置** / 退出登录
- 分拣员：蓝牙打印设置 / 商品管理（全角色 CRUD）/ 客户管理（全角色 CRUD）/ 报表统计/ 分拣出库 / 退出登录
- 库管：蓝牙打印设置 / 商品管理（全角色 CRUD）/ 客户管理（全角色 CRUD）/ 报表统计/ 分拣出库 / 退出登录
- 下单员：蓝牙打印设置 / 商品管理（全角色 CRUD）/ 客户管理（全角色 CRUD）/ 报表统计 / 退出登录

### 5. 系统设置（仅管理员）

> 📌 路径：「我的」页 →「系统设置」（**仅管理员可见**，其他角色不显示该入口）
> 🎯 用于配置智能录入所需的 AI 服务、打印机参数，以及了解数据备份情况。

**① AI 服务配置**

系统设置里分两个独立的 AI 服务区块，各自独立启用、独立保存，互不影响：

- **阿里语音（ASR，语音转文字）**：用于把你说的话转成文字，供智能录入的「语音录入」使用。
  - 启用开关：打开后语音录入才可用。
  - AccessKeyId / AccessKeySecret：阿里云账号的访问密钥（相当于账号密码，用于系统调用语音服务）。
  - AppKey：语音服务的应用标识。
  - 服务地域：选择你开通语音服务所在的区域。
  - 识别模型：选择语音识别用的模型。
- **通义千问（NLP，复杂语义理解）**：用于理解比较复杂的说法，比如「送 2 件手抓饼给东一路刀削面」这种口语化表达。
  - 启用开关：打开后复杂语义理解才可用。
  - API Key：通义千问服务的调用密钥。
  - 模型：选择使用的模型。

> 💡 **降级说明**：如果某个 AI 服务没有配置或没有启用，智能录入会自动降级为**纯规则引擎**——也就是靠系统内置的规则来匹配商品和客户。此时**文字匹配仍然可用**（输入商品名/客户名等关键字仍能识别），只是复杂口语和语音识别能力会受限。

**② 打印机配置**

- 品牌：选择你使用的打印机品牌（芯烨 / 佳博 / 汉印）。
- 纸宽：选择打印纸宽度（58mm / 80mm）。

设置好后，蓝牙打印送货单时会按这里的配置输出对应格式。

**③ 数据备份**

- 系统数据由**云开发平台每日自动备份**，无需手动操作，请放心使用。

## 第二部分：新建订单（核心操作）

> 📌 路径：首页 → 「新建订单」
> 🎯 4 角色均可新建订单（下单员为主要使用者）。

### 1. 选择客户

1. 点「客户名称」右侧搜索框。
2. 支持按**客户名/拼音/电话**模糊搜索、按**区域**下拉筛选；常用客户置顶。
3. 选中客户后自动回填：区域、联系人、电话；**商品价格自动带出该客户最近一笔订单的成交价**（上次价格，1.0）；该客户无历史订单时用商品默认价。
4. 还没有客户？点「+ 新增客户」快速新增。

### 2. 选择商品（选品弹窗 + 自动带出）

录单页为**单栏布局**：上方为客户选择，中间为订单明细，点击「+ 添加商品」打开选品弹窗（1.0 起彻底取消「收款方式」字段，所有订单不再有收款方式，统一默认未付款）。

**🟢 选客户自动带出上次订单（1.0）**：新建订单**选完客户后，系统自动把该客户上次订单的商品和数量带出来**（价格沿用上次成交价），商品行带「预填」标记。你直接在上面改数量、改价、删除，或继续「+ 添加商品」即可，不用从头录。

1. 在选品弹窗中点商品即可加入订单明细。
2. **默认仅展示前 3 个常购商品**（按该客户历史订单常购次数降序），**输入搜索词后展示全部匹配商品**（按商品名/规格/料号/拼音模糊搜索）。
3. 商品行显示：名称、规格、件价、包价（单位统一为「包」）。
4. 新增商品入口：录单时可直接新增。
5. **手动添加的商品数量默认 0**，自动带出的商品保留原数量，按实际核对修改即可。

### 3. 填写数量（件 + 包双轨）

- **添加商品时数量默认 0**，手动 + / − 调整，避免误录。
- 件数为大单位（整箱），包数为小单位（如 1 件 = 24 包）。
- 实时计算金额：`件数 × 件价 + 包数 × 包价`。
- 支持快速加减按钮 + 直接输入；输入框大号字体便于现场操作。

### 4. 自定义价格（1.0）

- **所有商品均可下单时改价**：点左侧订单明细中的商品价格，可修改件价/包价。
- **仅对当前订单有效**，不影响商品默认价格，也不影响其他订单/其他客户。

### 5. 提交订单

1. 填好备注（选填，如到货时间、特殊要求）。
2. 点底部「提交订单」，二次确认弹窗：「（区域-店名）的订单 数量与订单数量确认无误？」。
3. 提交成功提示「已推送至分拣员与库管（并行处理）」。
4. 弹出「是否立即打印送货单？」→ 见第七部分蓝牙打印。

> 💡 提交后即入「待分拣」；也可基于历史订单「复制订单」快速新建。

### 6. 转发客户微信（1.0）

新建订单提交后，系统会**自动弹出转发层**；在任意订单详情页也可点【📤 转发客户微信】。

- 转发的是**订单明细卡片**（绿色微信卡片）：丰淮商贸采购订单 + 客户/区域/时间 + 商品名称·数量·金额 + 合计 + 付款状态（未付款）+ 订单号。
- 接收方为该客户的**微信好友**（按客户联系人/电话定位）。
- 点【发送给客户微信】→ 订单标记「已转发」并记录时间，详情页「微信转发」行显示已转发状态。
- ⚠️ 仅转发订单信息供客户核对，**不含任何收款码/支付链接**，与 1.0 取消的「收款码卡片」是两回事。

## 第二部分补充：智能录入（文字/语音快速下单）

> 📌 路径：首页 → 「🗣 智能录入」卡片 或 新建订单页 → 「🗣 智能录入」按钮
> 🎯 4 角色均可使用，快速从文字或语音生成订单。

### 文字录入
1. 点首页「智能录入」卡片或新建订单页「智能录入」按钮。
2. 选择「文字录入」Tab。
3. 粘贴微信聊天记录或手动输入，如：「送 2 件手抓饼给东一路刀削面」或「手抓饼 2 件，老酸奶 10 包」。
4. 点「智能解析」→ 系统自动识别商品、数量、客户。

### 语音录入
1. 选择「语音录入」Tab。
2. 点麦克风按钮开始录音，说完后再点一下停止。
3. 语音自动转文字，点「智能解析」处理。

### 确认订单
1. 解析完成后显示订单草稿预览（客户 + 商品明细）。
2. 匹配到多个商品时，弹出选择列表让你选。
3. 选好后系统会记住你的选择，下次输入一样的内容自动按上次选的来。
4. 确认无误后点「确认生成订单」→ 跳转到新建订单页，可继续编辑后提交。

> 💡 智能录入只匹配库中已有的商品和客户，不会生成不存在的内容。如果输入的商品/客户无法匹配，需要手动从库中选择。

## 第四部分：分拣出库（原「分拣员工作台」+「库管工作台」合并）

> 💡 原型已把原「分拣员工作台」和「库管工作台」合并为「分拣出库」一个 Tab（微信 tabBar 上限 5 个）。页内含两段切换：① 分拣段（待分拣 / 已分拣）；② 出库段（待出库 / 已出库）。

### 1. 分拣段（待分拣 → 已分拣，一键完成）

Tab：待分拣(SUBMITTED，橙) / 已分拣(SORTED，紫)。

1. 点「待分拣」订单卡片 → 完整视图。
2. 可填写**分拣备注**（破损/缺货/替换品，可选，提供常用短语快捷按钮）。
3. 一键操作：🔍 **全部分拣 / 开始分拣**：订单 → 已分拣（`startSorting` / 全部分拣，一键「待分拣 → 已分拣」），推送库管待出库。

### 2. 出库段（待出库 → 已出库，库管一步确认）

Tab：待出库(SORTED，橙) / 已出库(CONFIRMED，蓝)。

- 「待出库」列表为已分拣、等待库管确认的订单。
- **出库确认（库管一步）**：点【出库确认】→ 订单 → 已出库（`confirmOrder` / 全部确认，一步确认「待出库(已分拣) → 已出库」）。
- 「已出库」列表卡片与订单详情显示「物流包裹：大件X · 中件X · 小件X」。

### 3. 权限与二期规划（件型/SLA 已实现，其余为二期）

- `sort:task` 控制「处理分拣」权限，`warehouse:confirm` 控制「出库确认」权限，默认全员开放，管理员可在「成员管理 → 权限配置」开关。
- **已实现（MVP）**：物流件型（大件/中件/小件）为出库确认时填写 `ship_*` 的已实现功能，订单详情/出库列表/报表/出库单展示「物流包裹：大件X·中件X·小件X」；「16:00 出库超时自动确认」的自动定时虽为二期规划（自动未实现），但原型保留「⏰模拟16:00通过」手动演示按钮（点击后当日待出库订单置为已出库）。
- 以下能力为**二期规划**，当前 MVP 已取消、不纳入主流程：`rejected`（已驳回，含必填原因驳回）、暂存配货（`pick_*` 并行配货）、「14:00 分拣超时自动确认」。`rejected` 状态保留定义但当前流程不触发，标注为遗留。

## 第五部分：赊销收款管理（1.0）

### 1. 赊销页（独立 Tab「💰赊销」，全角色可见）

赊销页含 **3 个 Tab** 与 1 个独立「✅ 收款确认」按钮：

- **📋 客户台账**：以客户为单位显示总账 = **应收总额 / 已收 / 未结清**（金额守恒：应收 = 已收 + 未结清）。顶部提供**搜索框**（按客户名称或区域实时筛选）。
- **📌 未结清**：按客户列出尚未结清的欠款（含部分收款、待确认）。
- **✅ 已结清**：已完全付清的客户/订单（已收 = 应收）。
- 独立「✅ 收款确认」按钮：聚焦收款确认动作（见 §3）。

客户台账每张卡片包含：

- **卡头**：客户名 + 区域，右侧显示**应收总额**大字与**状态标签**（未结清 / 部分已收·待确认 / 已结清，对应红 / 蓝 / 绿）。
- **金额守恒**：卡头三数关系为 应收总额 = 已收 + 未结清（「已收」含部分收款/折价，替代原「已结清」仅完全结清口径）。
- **订单明细**：每笔订单一行，显示订单号、剩余欠款，及**逾期天数徽标**（颜色同上，已登记待确认显示蓝色「待确认」）。
- 收款动作：**统一【收款】按钮**（1.0）按角色自动分流——下单员/分拣员点→弹金额框【收款登记】→提交后收款**下推库管**待确认（订单转蓝「待确认」）；库管点→直接看到待确认收款去【确认收款】，结清后变绿并移出未结清列表。按钮上带「·N 待确认」笔数提示。
- 仅显示有欠款的客户（未结清为 0 的可收起/隐藏）。

### 2. 收款状态机

| 状态 | 说明 |
|------|------|
| 未收款（unpaid） | 订单默认状态，无任何收款记录 |
| 待确认（pending） | 已登记收款但尚未全额结清（含待库管确认、或部分收款已确认仍有欠款） |
| 已收款（paid） | 累计实收 + 折价/货损 ≥ 订单金额，全部还清 |

### 3. 收款流程（统一两步：登记→库管确认，订单不再有收款方式）

> **1.0 统一「收款」按钮 + 1.0 角色分工**：订单详情、订单列表、赊销页（客户卡片 / 每笔订单行）均只有**一个【收款】按钮**，按当前角色自动分流——**下单员/分拣员**点开【收款登记】金额框（他们是收款责任人）；**库管**点【收款】只打开【确认收款】列表去逐笔确认、不登记收款（库管仅负责确认，无登记权限）；**管理员**兼有两者（有待确认则确认、否则可代登记）。无需再区分「登记」「确认」两个入口。

**第 1 步：收款登记（下单员/分拣员/管理员，点【收款】）**

1. 在订单详情、订单列表或赊销页点【收款】。
2. 弹窗填：**收款方式（现金 / 微信，用于台账"现余/微信"拆分）**、**实收金额**（默认带出剩余欠款，可改）、**折价/货损金额（可选）**、备注。
3. 点【确定收款】→ 订单转「待确认」蓝，Toast「已登记收款，已下推库管确认」，收款动作同步下推至库管待确认队列。**库管点【收款】时不会进入此登记弹窗。**

**第 2 步：确认收款（库管/管理员，点【收款】）**

1. 库管在赊销页客户卡片（或订单详情）点【收款】→ 打开待确认收款列表（若当前角色无待确认收款，提示「暂无待确认收款，请等待下单员/分拣员登记」）。
2. 逐笔【确认】→ 若订单全部结清则转「已收款」绿；仍有欠款保持「待确认」（未结清）。
3. 客户累计欠款实时扣减，Toast「已确认收款，剩余欠款 ¥xxx」（或「订单结清 ✓」）。

> 📤 **导出报表（赊销页）**：支持周期选择（全部 / 今日 / 本周 / 本月 / 自定义），明细行含订单号（订单号含时间故不重复显示时间列），汇总行显示 应收 / 已收 / 未结清（台账 / 汇总 / 导出三处口径统一为「已收」）。

> 💡 支持部分收款：一次登记部分金额，多次累计至还清。剩余欠款 = 订单金额 − 累计实收 − 累计折价/货损。
> ℹ️ 本功能为内部赊销对账管理，**不涉及任何第三方支付收款码**；订单/送货单/页面均不印制商户收款码（259号文合规内容已下线）。

## 第九部分：常见问题（FAQ）

### 订单相关
**Q: 订单提交后发现商品/价格/客户错了怎么办？**  
A: 4 角色均可编辑：订单详情 → 「编辑订单」复制到编辑页修改后重新提交；或「复制订单」快速克隆改完再提交。

**Q: 下单后客户要求加几样商品？**  
A: 编辑该订单加商品后重新提交，或新建追加单（备注写「追加单」）。

**Q: 为什么录单默认只显示几个商品？**  
A: 默认仅显示该客户最常购的 4 个商品；输入关键字搜索后会展示全部匹配商品。

**Q: 为什么添加商品数量是 0？**  
A: 1.0 起数量默认 0，由用户按实际 + / − 调整，避免误录多算金额。

### 收款相关
**Q: 登记收款后客户还没结清，怎么处理？**  
A: 状态保持「待确认（未结清）」，支持多次登记部分收款累计；库管确认后仍未结清则继续显示欠款。

**Q: 折价/货损金额怎么填？**  
A: 实收 ≠ 应付时填（如 100 元货品实收 90 元，折价 10 元），用于对账时记录让利/货损。

### 打印相关
**Q: 蓝牙打印机缺纸/打印中断怎么办？**  
A: 补纸后再次点「打印」即可，同一订单支持多次打印。

### 权限相关
**Q: 分拣员能下单/改单吗？**  
A: 可以，1.0 起 4 角色均可下单/改单/删单；分拣员还负责一键分拣（待分拣→已分拣）；驳回为遗留状态（二期规划，当前不触发）。

**Q: 谁可以确认收款？**  
A: 只有库管和管理员能「确认收款」；登记收款由下单员/分拣员/管理员操作。
