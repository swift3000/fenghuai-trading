## 第一部分：微信小程序端操作指南（采购员/库管/管理员通用）

---

### 1. 登录与首页

#### 1.1 打开小程序
1. 在微信中搜索「丰淮商贸采购下单助手」或扫描小程序码。
2. 首次打开会自动调用微信授权登录，点击「允许」即可。
3. 若该微信号未绑定系统账号（users.wx_openid 为空），页面会提示：
   > 该微信账号尚未绑定，请联系管理员
   请联系老板（管理员）在后台新增用户时绑定您的 openid。

#### 1.2 首页（我的工作台）
登录成功后默认进入首页，展示：
- 顶部：当前用户角色（采购员/库管/管理员）、区域、姓名
- 快捷入口卡片（根据角色显示不同）：
  - 采购员：➕ 新建订单、📦 我的订单、👥 客户、📒 商品、🖨 蓝牙打印配对
  - 库管：✅ 待确认订单、📋 已确认订单、🖨 打印、👥 客户、📒 商品
  - 管理员：📊 今日概览、✅ 待确认、📋 全部订单、➕ 新建订单、🖨 打印

---

### 2. 新建订单（核心操作）

> 📌 路径：首页 → 「新建订单」或「➕」悬浮按钮  
> 🎯 必做角色：采购员（orderer）、管理员（admin，模拟下单）

#### 2.1 选择客户
1. 点「客户名称」右侧 🔍 搜索框。
2. 支持按**客户姓名/电话**模糊搜索，按**区域**下拉筛选。
3. 选中客户后自动回填：区域、联系电话、联系人。
   - 若联系电话/联系人为空，可在订单中手动填写。
   - 区域只做展示，不可改。
4. 还没有客户？点右上角「+ 新增客户」快速新增（见第 5 章）。

#### 2.2 添加商品（购物车）
1. 点「+ 添加商品」进入商品选择页。
2. 支持：
   - 顶部 🔍 搜索框：按 SKU / 商品名 / 分类 模糊匹配。
   - 顶部「分类」Tab：蔬菜 / 肉类 / 冻品 / 调料 / 粮油 / 水产 / 其他（切换查看）。
3. 选择商品后弹出「数量选择」：

**数量选择规则**（展示端"件+零"双轨录入，订单详情/报表端仅显示件）：

| 商品定价模式 | 录入字段 | 说明 |
|---|---|---|
| case（件+零） | 件数 + 零数 | 零数自动换算计入小计。例：有机西红柿 2件+3零 = 2 + 3/件含量 计费 |
| piece（纯件） | 件数 | 零数不可填 |
| unit（纯个） | 个数（=零数） | 件数不可填 |

- 对单价的特别说明：
  - 93 开头的 SKU：**可调价**，弹窗内可临时改件价/零价（下单员权限内即可）。
  - 客户 `is_adjustable=true`：允许临时改该客户所有商品单价。
  - 其他：普通商品单价不可在下单页修改（展示只读）。
- 填完点「加入购物车」。
4. 已选商品展示在订单页面中，可：
   - 点「+」/「−」调整数量；
   - 点「×」移除；
   - 点商品行再次弹出数量弹窗修改。
5. 页面底部实时计算合计金额 = Σ 每件小计。

#### 2.3 其他信息
- 支付方式：默认「现金」，可下拉改「转账 / 赊账」。
- 订单备注：选填，例如「多加一份调料」。

#### 2.4 提交订单
1. 点底部红色「提交订单」按钮。
2. 二次确认：客户、件数、金额是否正确。
3. 提交成功 → 弹出：
   > 订单提交成功！订单号 FH-XXXXXX
4. 之后自动弹「是否立即蓝牙打印小票？」（见第 3 章蓝牙打印）。
   - 取消 → 稍后在「订单详情」里打印；
   - 确认 → 进入蓝牙打印流程。

### 3. 蓝牙打印送货小票（小程序端）

> 📌 v1.0 必做功能，采购员随用随打。  
> 🔧 打印机：58mm 通用 BLE 热敏打印机（芯烨 XP-58IIH / 佳博 GP-58MBIII+ / 美团 MT-58W 均兼容）。

#### 3.1 首次配对蓝牙打印机（一次配对，自动记住）
1. 首页卡片点「🖨 蓝牙打印配对」，或订单详情页点「打印」。
2. 首次授权小程序：
   - 请开启手机 **蓝牙** 与 **定位**（Android 必须）。
   - 小程序授权弹框一律点「允许」。
3. 自动进入打印机扫描列表，显示名称/信号强度：
   - 推荐先开打印机电源并装好纸；
   - 等约 3-10 秒显示结果；
   - 找不到时点「重新搜索」。
4. 点击目标打印机名称完成连接。
5. 弹出「连接成功」后自动记住，下次无需配对（除非换打印机）。

#### 3.2 打印小票
1. 订单提交成功 → 点「立即打印」；或订单详情 → 点「🖨 打印送货单」。
2. 若未配对，自动进入 3.1 配对流程。
3. 已配对则自动开始打印，显示「正在发送指令… 10%/30%/…/100%」。
4. 打印完成：
   - 自动撕纸或手动撕纸。
   - 订单状态自动标记为「已打印」。

#### 3.3 小票内容说明
打印内容从上到下依次为：
```
丰淮商贸·采购小票          ← 居中、2倍放大加粗
───────────────────────────
订单号：FH-YYYYMMDD-NNNN
客户：XX餐厅        区域：汉滨区
时间：YYYY-MM-DD HH:MM
经办人：张三
───────────────────────────
[表头 加粗]  商品 | 数量 | 金额
───────────────────────────
有机西红柿    1件5零  ¥145.00
土鸡蛋        5盒      ¥150.00
五花肉        5斤      ¥ 20.50
───────────────────────────
合计：¥ 315.50              ← 加粗放大
───────────────────────────
[ 订单号二维码 ]
[ 订单号条形码 CODE128 ]
───────────────────────────
        感谢惠顾！


（走纸 3 行，方便手撕）
```

#### 3.4 异常处理
| 异常现象 | 处理方法 |
|----------|----------|
| 搜索不到打印机 | ① 重启打印机蓝牙配对 ② 靠近手机 ③ 打开并允许位置信息权限 |
| 连接失败（多次重试） | 先关闭后台其他蓝牙 App；在系统蓝牙列表中"忽略该设备"后重试 |
| 打印中文字错位/乱码 | 选择 ESC/POS 标准机型（三款推荐机型已在后台预设） |
| 半页打印中断 | 再次点「打印」，支持同一订单重打多次 |
| 完全无法打印 | 降级：小程序自动保存小票图片到相册，用户可通过手机自带相册打印/微信发送到电脑打印 |

### 4. 订单管理（小程序端）

#### 4.1 订单列表
- 路径：首页 → 「我的订单」（采购员） / 「待确认订单」「已确认订单」（库管）/ 「全部订单」（管理员）。
- 默认按「下单时间」倒序。
- 筛选项：
  - 状态 Tab：全部 / 待确认 / 已确认 / 已取消
  - 日期范围：近 3 天 / 近 7 天 / 自定义
  - 客户搜索（姓名/电话）
- 列表每行显示：订单号、客户名、金额、下单时间、状态标签（不同颜色）。

#### 4.2 订单详情
点击订单行进入详情，显示：
- 顶部：订单号 + 完整状态标签
- 客户信息栏
- 商品明细表格：商品名、件数（仅显示件，不展示 +零）、单价、小计金额 🔳
- 底部：合计金额 + 支付方式 + 备注 + 操作按钮

**操作按钮（按角色显示）**：

| 按钮 | 显示角色 | 触发动作 |
|------|----------|----------|
| 确认订单 | 库管、管理员 | 订单状态 待确认 → 已确认（只能点 1 次） |
| 打印送货单 | 全部 | 走第 3 章蓝牙打印流程（再次打印也可以） |
| 复制为新订单 | 全部 | 以该订单商品内容克隆一个新的草稿订单（只换客户即可快速下单） |
| 取消订单 | 管理员 | 弹出原因输入框 → 状态改为"已取消" |

### 5. 客户维护（小程序端）

> 🎯 权限：采购员（自己新建的可改）、管理员（全部可改）

#### 5.1 新增客户
- 路径：首页「👥 客户」→ 右上角「+」
- 填写：
  - 客户姓名（必填）
  - 区域（必填，下拉 11 个预置区域）
  - 详细地址（选填）
  - 联系人（选填）
  - 联系电话（选填，填了搜索更快）
  - 是否可调价客户（默认关闭；若开则该客户下订单允许临时改所有商品价格）
- 点「保存」。

#### 5.2 修改客户
- 客户列表 → 点击某客户 → 右上角「编辑」
- 区域、姓名、电话、地址、可调价状态均可修改。

### 6. 商品维护（小程序端）

> 🎯 权限：采购员（自己新建可改）、管理员（全部可改）

#### 6.1 新增商品
- 路径：首页「📒 商品」→ 右上角「+」
- 必填：
  - SKU 编码（唯一，3-50 位；建议用条码后 6 位；93 开头自动变为可调价商品）
  - 商品名称
  - 单位（件/盒/箱/斤/包 等）
  - 定价模式（下拉三种：case / piece / unit）
- 选填：分类、规格
- 价格（必填 ≥ 0）：
  - 件价（必）
  - 零价（选，case 模式必填）
  - 件含量（case 模式必填，每几件装 = 几零）
- 保存。

#### 6.2 修改商品
- 商品列表 → 点某商品 → 编辑。
- SKU 编码创建后不允许改。改价格不影响历史订单（历史订单使用的是"下单时快照"）。

## 第二部分：Web 管理后台操作指南（库管/管理员）

### 7. 后台登录与首页

#### 7.1 登录
1. 打开后台网址。
2. 输入：用户名 + 密码。
3. 点「登录」。
   - 角色为 warehouse（库管）：默认进入「待确认订单」。
   - 角色为 admin：默认进入「订单」页。
   - 其他错误：弹用户名或密码错误。

#### 7.2 页面结构
- 顶部导航条：左侧 LOGO「丰淮商贸后台」；右侧当前用户名 + 退出。
- 一级标签页（5 个）：订单 / 商品 / 客户 / 区域 / 用户。

### 8. 订单管理（Web 后台核心）

#### 8.1 订单列表与筛选
- 进入「订单」标签页。
- 筛选：状态、日期范围、客户搜索、经办人（可选）。
- 表格列：
  | 列 | 说明 |
  |---|---|
  | □ 复选框 | 勾选用于批量打印 / 批量导出 |
  | 订单号 | 可点进详情 |
  | 客户 | |
  | 区域 | |
  | 件数（汇总） | 仅显示件（+零在详情看） |
  | 金额 | |
  | 下单时间 | |
  | 经办人 | |
  | 打印状态 | 未打印 / 已打印 |
  | 状态标签 | 待确认（橙）/已确认（绿）/已取消（灰） |

#### 8.2 批量确认订单（库管每天上午必做）
1. 点筛选项「状态 = 待确认」。
2. 点表头全选框「□ 全选」 → 选中所有待确认。
3. 点表格上方按钮「✅ 批量确认」。
4. 二次确认弹框：确定把 X 条订单变为「已确认」？
5. 完成后，刷新表格。状态变绿，按钮变灰。

#### 8.3 Excel 导出（核心数据输出）
- **方式 A：按筛选条件导出（推荐）**
  1. 选择日期范围 + 状态等筛选。
  2. 点顶部「📤 导出 Excel」按钮。
  3. 浏览器自动下载 `.xlsx` 文件：
     > `订单导出_2026-07-30_10-30-00.xlsx`
  4. 打开 Excel，里面 1 个 Sheet = 订单明细平铺（每订单的每件商品占 1 行）。列字段：订单号、下单时间、客户、区域、商品、规格、SKU、件数、零数、件价、零价、小计、订单总金额、状态、经办人、备注。

- **方式 B：勾选导出**
  - 勾选若干订单行 → 点「📤 导出已勾选」。

#### 8.4 打印多联送货单（241mm 针式打印机）
> 📌 走 `window.print()` + CSS `@page size: 241mm 140mm`；打印前浏览器弹出"打印预览"可选页边距、缩放。

1. 勾选要打印的订单（建议≤50 份一次；1 单 = 1 页纸）。
2. 点顶部「🖨 打印送货单」。
3. 弹出新浏览器 Tab，内容为按针式多联单排版的表格（商品行 2 行抬头）。
4. 自动调浏览器打印对话框：
   - 打印机：选 EPSON LQ-630K 或对应针式打印机；
   - 纸张大小："241×140mm 多联"或自定义（若驱动支持）；
   - 页边距："最小"或"默认"；
   - 方向：纵向。
5. 点「打印」，多联纸三联（白/红/黄）同时出纸，直接撕即可。
6. 完成后，后台自动把这些订单标记为「已打印」。

### 9. 商品/客户/区域/用户（Web 后台）

各标签页操作流程相同（CRUD），此处统一说明。

| 标签页 | 可操作角色 | 说明 |
|--------|-----------|------|
| 商品 | 采购员（仅本人创建）、管理员（全部） | 增 / 改 / 停用；停用后下单不可选 |

| 用户 | 仅管理员 | 增 / 改 / 重置密码 / 禁用；绑定 openid（小程序登录用） |

#### 9.1 新增一个小程序采购员（管理员示例）
1. 进入「用户」标签页。
2. 点「+ 新增用户」。
3. 填写：
   - 用户名（登录名，英文+数字）
   - 姓名（中文，展示用）
   - 初始密码（6 位以上，员工首次登录后建议改）
   - 角色：选「采购员」
   - 区域：选汉滨区（或负责区域）
   - 手机：选填
4. 保存。
5. 让采购员打开小程序 → 登录 → 自动绑定到当前 wx_openid。
   > 若需手动绑定：在用户编辑中粘贴 openid 保存。

## 第三部分：常见问题（FAQ）

### 订单相关
**Q: 订单提交后发现商品错了/价格错了/客户错了怎么办？**  
A: v1.0 不支持改明细。操作：① 让管理员在订单详情点「取消订单」并填原因；② 重新下单。或直接用「复制为新订单」快速复制，改完再提交。

**Q: 下单后客户要求加几样商品？**  
A: 直接新建一份追加订单即可（备注写"追加单"）。

### 打印相关
**Q: 后台用 Excel 导出后打不开？**  
A: 用 Microsoft Excel 2016+ 或 WPS 打开；老版本 Excel 另存为兼容格式。

**Q: 针式打印机切纸不对？**  
A: 驱动里设纸张大小为 241×140mm；或在 CSS @page 微调高度。

**Q: 蓝牙打印机缺纸怎么办？**  
A: 装纸后再次点「打印」即可，同一订单支持多次打印。

### 权限相关
**Q: 采购员在小程序找不到"用户"/"区域"入口？**  
A: 正常，采购员权限不开放用户和区域管理。

**Q: 库管不能改商品？**  
A: 正常，库管只管确认和打印。需要改请联系采购员或管理员。
