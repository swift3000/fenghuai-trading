# 丰淮商贸采购下单助手 · 工期与工作量评估（MVP 专项）

> **版本**：v1.0（MVP 专项）  
> **日期**：2026-08-05  
> **编写依据**：原型 1.0（MVP 定稿）、PRD(MVP)、TDD(MVP)、《小程序 MVP 落地计划与技术架构》  
> **一句话结论**：MVP（最终范围，11 项功能）生产化为微信小程序 + 云开发，约 **30 人天**；1 人全栈 6–7 周，2 人并行 4 周。运行年平台费 269(个体户)/539(公司) 元。

| 项 | 说明 |

---

## 2. MVP 工作量拆解（≈30 人天）

| 模块 | 任务 | 人天 |
|------|------|------|
| W0 准备 | 云开发环境、微信认证、商品/客户底表导入 | 2 |
| W1 地基 | 登录 + 四角色权限、商品/客户 CRUD（**全角色**）、云数据层 | 8 |
| W2 核心业务 | 新建订单、分拣出库（分拣段 + 出库段）、收款两步状态机、赊销（客户台账/未结清/已结清 三栏 + 收款确认按钮、已收口径） | 12 |
| W3 模板与适老 | 销售单打印/转发（**西安迈尚模板**：制单人电话取登录人、独立备注列、去 NO.）、全局字号缩放 | 4 |
| W4 联调上线 | 真机调试、蓝牙打印、体验版、审核发布 | 4 |
| **合计** | | **≈ 30 人天** |

## 4. 成本测算

### 4.1 开发费（建议另报）
按人天单价计算，MVP ≈30 人天。原型包干（5,000 元）仅覆盖 HTML 验证，不含本生产化工作量。

### 4.2 运行年费（客户自付，已确认）
| 项 | 金额 |
|----|------|
| 微信认证 | 个体户 30 / 公司 300 元/年 |
| 云开发（个人版 19.9/月 或 初创版 99/月） | 239 / 1188 元/年 |
| 微信支付手续费 | 0（不开通，赊销记账模式） |
| 短信/域名/服务器 | 0 |
| **首年合计** | 个体户 ≈269 / 公司 ≈539 元（极限最低）；初创版 ≈1488 元（推荐） |

> 运行成本极低，不构成决策障碍。

## 5. 风险与决策门

| 依赖/风险 | 影响 | 缓解 |
|-----------|------|------|
| 打印机型未定（芯烨/佳博/汉印） | 影响 W4 真机调试 | 提前收集客户在用机型 |
| 收款状态机未一次做对 | 赊销欠款额算错（数据命门） | W2 集中设计 + 单元校验 |
| 角色权限未设计成可配置 | 后续细分返工 | W1 抽成配置表 |
