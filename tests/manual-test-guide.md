## 测试步骤

### 1. 启动测试
1. 打开微信开发者工具
2. 项目已自动打开：`fenghuai-trading`
3. 等待编译完成

### 2. 页面渲染测试
#### 首页
- [ ] 打开首页 `pages/index/index`
- [ ] 检查页面是否正常渲染
- [ ] 检查用户信息、角色徽章显示
- [ ] 检查快捷操作按钮（新建订单、商品管理、客户管理等）
- [ ] 检查今日订单列表

#### 新建订单页
- [ ] 点击"新建订单"按钮
- [ ] 检查页面是否正常渲染
- [ ] 测试客户选择弹窗
- [ ] 测试商品选择弹窗
- [ ] 测试商品添加到订单
- [ ] 测试客户选择
- [ ] 测试总价计算

#### 订单详情页
- [ ] 点击某个订单
- [ ] 检查订单详情显示
- [ ] 检查订单状态
- [ ] 检查操作按钮（转发、分拣、确认等）

#### 赊销管理页
- [ ] 打开赊销页面
- [ ] 检查待收款列表
- [ ] 测试收款确认功能

#### 商品管理页
- [ ] 打开商品管理页面
- [ ] 检查商品列表
- [ ] 测试商品搜索
- [ ] 测试商品编辑

#### 客户管理页
- [ ] 打开客户管理页面
- [ ] 检查客户列表
- [ ] 测试客户搜索
- [ ] 测试客户编辑

### 3. 功能测试
#### 下单流程
1. [ ] 新建订单
2. [ ] 选择客户
3. [ ] 添加商品
4. [ ] 确认订单
5. [ ] 检查订单是否创建成功

#### 转发流程
1. [ ] 选择已创建订单
2. [ ] 点击"转发"按钮
3. [ ] 检查转发状态

#### 分拣流程
1. [ ] 选择已转发订单
2. [ ] 点击"分拣"按钮
3. [ ] 检查分拣状态

#### 库管确认
1. [ ] 选择已分拣订单
2. [ ] 点击"库管确认"按钮
3. [ ] 检查确认状态

#### 赊销确认
1. [ ] 创建赊销订单
2. [ ] 检查赊销记录
3. [ ] 测试收款确认

### 4. 角色权限测试
#### 管理员
- [ ] 可以访问所有页面
- [ ] 可以管理所有角色权限
- [ ] 可以控制功能开关

#### 销售员
- [ ] 可以创建订单
- [ ] 可以查看客户和商品
- [ ] 不能访问管理页面

#### 库管员
- [ ] 可以确认分拣
- [ ] 可以查看库存
- [ ] 不能创建订单

### 5. 数据测试
- [ ] 测试云函数调用
- [ ] 测试数据增删改查
- [ ] 测试数据同步
