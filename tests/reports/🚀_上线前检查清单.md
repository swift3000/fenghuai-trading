## 📱 手动测试步骤（必须完成）

### 步骤 1: 编译项目
```
在微信开发者工具中点击"编译"按钮
```

### 步骤 2: 登录测试
1. 点击"微信一键登录"
2. 验证登录成功
3. 确认显示"管理员"标签

### 步骤 3: 新建订单流程 ⭐核心
1. 点击"新建订单"按钮
2. 点击"选择客户" → 验证弹窗弹出
3. 搜索客户 → 验证搜索结果
4. 点击客户 → 验证客户被选中
5. 点击"添加商品" → 验证弹窗弹出
6. 搜索商品 → 验证搜索结果
7. 选择商品数量 → 点击"添加"
8. 验证商品添加到列表
9. 点击"提交订单"
10. 验证订单创建成功，跳转到订单列表

### 步骤 4: 订单详情测试
1. 在订单列表点击刚创建的订单
2. 验证订单详情页面正常显示
3. 验证包含：客户信息、商品列表、金额、状态
4. 验证"打印"按钮正常

### 步骤 5: 商品管理测试
1. 点击"商品管理"
2. 验证商品列表显示
3. 点击"添加商品" → 填写信息 → 保存
4. 验证商品添加成功
5. 尝试编辑和删除商品

### 步骤 6: 客户管理测试
1. 点击"客户管理"
2. 验证客户列表显示
3. 点击"添加客户" → 填写信息 → 保存
4. 验证客户添加成功

### 步骤 7: 赊销管理测试
1. 点击"赊销" Tab
2. 验证客户台账显示
3. 验证统计数据正确
4. 点击"登记收款" → 输入金额 → 确认
5. 验证收款成功
6. 点击"导出" → 验证 CSV 文件生成

### 步骤 8: 分拣出库测试
1. 点击"分拣出库" Tab
2. 验证分拣任务列表显示
3. 点击"分拣" → 验证分拣完成
4. 验证库管确认功能

### 步骤 9: 报表导出测试
1. 点击"报表导出"
2. 验证三种统计维度（商品/客户/收款）
3. 验证数据表格显示
4. 验证导出功能

### 步骤 10: 成员管理测试
