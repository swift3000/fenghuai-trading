# 丰淮商贸采购下单助手

> 方案B：微信小程序（全员使用）+ 极简Web后台（3页），蓝牙打印+Excel导出

## 项目概述

为丰淮商贸的一线下单员、库管和老板提供一套**超轻量、低成本、即开即用**的小程序下单解决方案。

- **工期**：3周（21自然日）
- **预算**：5,000元（包干价）
- **技术栈**：微信云开发 + 原生小程序 + 单HTML Web后台

## 核心功能

| 模块 | 小程序（全员） | 极简Web后台（库管/管理员） |
|------|:---:|:---:|
| 登录/权限 | ✅ 微信一键登录 | ✅ 账号密码登录 |
| 客户/商品管理 | ✅ 增删改 | ❌ 不做 |
| 订单录入/管理 | ✅ 核心功能 | ❌ 不做 |
| 订单确认（库管） | ✅ | ✅ 第1页：订单确认 |
| Excel导出（3种） | ✅ | ✅ 第2页：导出中心 |
| 送货单打印 | ✅ 蓝牙打印（便携热敏） | ✅ 第3页：浏览器打印（241mm针式） |

## 角色权限

| 功能 | 下单员 | 库管 | 管理员 |
|------|:---:|:---:|:---:|
| 新建/修改/删除订单 | ✅ | ❌ | ✅ |
| 查看全部订单 | ✅ | ✅ | ✅ |
| 确认订单（→已确认） | ❌ | ✅ | ✅ |
| 蓝牙打印送货单 | ✅ | ✅ | ✅ |
| Web后台3页操作 | ❌ | ✅ | ✅ |
