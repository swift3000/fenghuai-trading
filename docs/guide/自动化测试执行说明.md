# Computer Use 自动化测试执行说明

## 当前状态

Computer Use 技能需要通过 Codex 的 `node_repl` 环境运行，不能直接在 shell 中执行。

## 执行方式

### 方式 1: 通过 Codex 直接调用 Computer Use

请在 Codex 对话框中输入：
```
使用 computer-use 技能进行微信小程序全自动化测试
```

Codex 将自动：
1. 打开微信开发者工具
2. 编译项目
3. 测试所有功能页面
4. 每个步骤截图
5. 获取控制台日志
6. 生成完整测试报告

### 方式 2: 手动测试（推荐立即执行）

由于自动化测试需要额外的环境配置，建议先进行手动测试：

#### 快速测试步骤：

1. **打开微信开发者工具**
   - 点击 Dock 栏中的微信开发者工具图标

2. **打开项目**
   - 文件 → 打开项目
   - 选择：`/Users/god/Desktop/项目/github/fenghuai-trading`

3. **编译项目**
   - 点击顶部工具栏的"编译"按钮
   - 等待编译完成

4. **测试登录**
   - 点击"微信一键登录"按钮
   - 截图保存（Cmd+Shift+4）

5. **测试新建订单**
   - 点击"新建订单"按钮
   - 选择客户
   - 添加商品
   - 提交订单
   - 截图保存

6. **测试其他页面**
   - 订单列表
   - 商品管理
   - 客户管理
   - 赊销管理
   - 分拣出库
   - 我的页面
   - 成员管理
   - 每个页面截图保存

7. **检查控制台日志**
   - 微信开发者工具 → 调试器 → Console
   - 检查是否有错误
   - 截图保存
