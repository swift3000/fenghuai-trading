## 🎯 使用场景

### 场景 1: 日常测试
```bash
./tests/diagnose.sh          # 先诊断
./tests/run-full-automation.sh  # 再测试
```

### 场景 2: 部署前检查
```bash
node tests/upload-cloudfunctions.js create-config
node tests/upload-cloudfunctions.js upload-all
./tests/run-full-automation.sh
```

### 场景 3: 配置调整
```bash
node tests/config-manager.js init
node tests/config-manager.js set test.timeout 60000
node tests/config-manager.js list
```

### 场景 4: 查看报告
```bash
# 打开最新的 HTML 报告
open reports/test-report-*.html
```
