# 🚨 快速诊断与修复指南

## 当前问题汇总

根据用户反馈和自动化测试，发现以下问题：

### 1️⃣ 登录失败
**现象**: 点击"微信一键登录"提示"登录失败，请重试"

**诊断步骤**:
```bash
# 1. 检查云函数是否部署
cd cloudfunctions
ls -la

# 2. 检查 init-db 是否执行
# 在微信开发者工具中右键 init-db → 运行测试 → 参数 {}
```

**解决方案**:
1. 在微信开发者工具中右键 `cloudfunctions` → "上传并部署：云端安装依赖"
2. 运行 `init-db` 云函数初始化数据库
3. 检查云函数日志查看错误信息

### 2️⃣ 订单详情空白
**现象**: 点击订单后页面显示空白

**可能原因**:
- 云函数未部署，数据无法查询
- 订单 ID 传递错误
- 数据格式不匹配

**诊断步骤**:
```bash
# 检查订单云函数
cat cloudfunctions/orders/index.js | grep -A 30 "case 'detail'"
```

**解决方案**:
1. 确保 orders 云函数已上传部署
2. 检查控制台日志查看具体错误
3. 验证数据库中存在订单数据

### 3️⃣ 客户选择无反应
**现象**: 新建订单时点击"选择客户"弹窗无响应

**可能原因**:
- 客户数据未加载
- 弹窗组件绑定错误
- 云函数调用失败

**解决方案**:
1. 确保 customers 云函数已部署
2. 检查客户数据是否已初始化
3. 查看控制台日志定位错误

### 4️⃣ UI 错位、卡顿
**现象**: 界面元素位置不对，响应慢

**解决方案**:
1. 检查样式文件是否正确引入
2. 优化数据加载逻辑
3. 使用微信开发者工具的 Performance 面板分析
