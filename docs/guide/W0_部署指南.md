# W0 准备工作：云函数部署与数据库初始化

> 执行顺序：数据库集合创建 → 插入预置数据 → 部署云函数 → 初始化系统配置

---

## 📋 步骤 1：创建 12 个数据库集合

### 操作路径
微信开发者工具 → 左侧「云开发」→「数据库」→「添加集合」

### 集合清单（12 个）
1. `users` - 用户信息
2. `regions` - 区域信息
3. `products` - 商品档案
4. `customers` - 客户档案
5. `orders` - 订单主表
6. `order_items` - 订单明细
7. `payments` - 收款登记
8. `product_aliases` - 商品别名
9. `customer_aliases` - 客户别名
10. `order_logs` - 订单日志
11. `system_config` - 系统配置
12. `perm_configs` - 角色权限覆盖（per-role permission overrides）

### 注意事项
- 集合名称必须**完全一致**（区分大小写）
- 权限设置：所有集合设置为「所有用户可读写」
- 索引：暂不创建，后续根据查询需求添加

---

## 📋 步骤 2：插入 regions 预置数据

### 操作路径
云开发 → 数据库 → 选择 `regions` 集合 →「添加数据」→「批量添加」

### 数据内容（复制以下 JSON）
```json
[
  { "_id": "1", "name": "汉滨区", "sort": 1, "status": 1 },
  { "_id": "2", "name": "汉阴县", "sort": 2, "status": 1 },
  { "_id": "3", "name": "石泉县", "sort": 3, "status": 1 },
  { "_id": "4", "name": "宁陕县", "sort": 4, "status": 1 },
  { "_id": "5", "name": "紫阳县", "sort": 5, "status": 1 },
  { "_id": "6", "name": "岚皋县", "sort": 6, "status": 1 },
  { "_id": "7", "name": "平利县", "sort": 7, "status": 1 },
  { "_id": "8", "name": "镇坪县", "sort": 8, "status": 1 },
  { "_id": "9", "name": "旬阳市", "sort": 9, "status": 1 },
  { "_id": "10", "name": "白河县", "sort": 10, "status": 1 },
  { "_id": "99", "name": "外县", "sort": 99, "status": 1 }
]
```

### 字段说明
- `_id`: 自定义 ID（字符串类型）
- `name`: 区域名称（字符串类型）
- `sort`: 排序值（数字类型）
- `status`: 状态（1=启用，数字类型）

### 注意事项
- `_id` 必须是字符串类型（加引号）
- `sort` 值：汉滨区=1，白河县=10，外县=99
- `status` 全部为 1（启用状态）

---

## 📋 步骤 3：部署 10 个云函数

### 操作路径
微信开发者工具 → 右键点击 `cloudfunctions` 目录 → 依次部署 10 个云函数

### 部署清单（10 个）
1. `auth` - 用户鉴权
2. `products` - 商品管理
3. `customers` - 客户管理
4. `orders` - 订单管理
5. `users` - 用户信息
6. `regions` - 区域查询
7. `receivable` - 收款登记
8. `system` - 系统配置
9. `smart` - 智能识别
10. `report` - 报表统计

### 操作步骤
1. 右键点击 `cloudfunctions/auth` 目录
2. 选择「上传并部署：云端安装依赖」
3. 等待上传完成（首次部署会安装 package.json 中的依赖）
4. 重复以上步骤，依次部署所有 10 个云函数

### 注意事项
- 每个云函数都需要单独部署
- 首次部署会安装依赖，需要等待几分钟
- 部署成功后，云开发控制台会显示云函数列表

---

## 📋 步骤 4：初始化 system_config 系统配置

### 操作路径
云开发 → 数据库 → 选择 `system_config` 集合 →「添加数据」

### 初始配置数据（复制以下 JSON）
```json
{
  "_id": "ai_config",
  "type": "ai",
  "asr": {
    "enabled": false,
    "appId": "",
    "appKey": "",
    "secretKey": ""
  },
  "nlp": {
    "enabled": false,
    "apiKey": ""
  },
  "voice": {
    "enabled": false,
    "voiceId": ""
  },
  "printer": {
    "enabled": false,
    "printerId": "",
    "printerName": ""
  },
  "status": 1,
  "createTime": "2026-08-11T00:00:00.000Z"
}
```

### 配置说明
- `asr`: 腾讯云语音识别配置（后续启用）
- `nlp`: 通义千问 NLP 配置（后续启用）
- `voice`: 腾讯云语音合成配置（后续启用）
- `printer`: 打印机配置（后续启用）
- 所有配置初始状态为 `enabled: false`

## 🚨 常见问题

### Q1: 云函数部署失败
**解决方法**：
1. 检查网络连接
2. 检查 package.json 依赖是否完整
3. 尝试重新部署

### Q2: 数据库集合创建失败
**解决方法**：
1. 检查集合名称是否重复
2. 检查是否达到集合数量限制（免费版 25 个）

### Q3: regions 数据导入失败
**解决方法**：
1. 检查 JSON 格式是否正确
2. 检查 `_id` 是否重复
3. 检查字段类型是否正确
