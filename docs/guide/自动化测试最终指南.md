## 🎯 推荐测试方案

### 方案 A: 使用 Computer Use 技能（全自动）

**步骤**:
1. 在 Codex 中启用 `computer-use` 技能
2. 授权访问微信开发者工具
3. 运行自动化测试脚本

**优点**: 完全自动化，无需手动操作  
**缺点**: 需要配置 Computer Use 权限

### 方案 B: 手动测试 + 截图（推荐）

**步骤**:

#### 1. 编译项目
```bash
微信开发者工具 → 打开项目 → 点击"编译"按钮
```

#### 2. 测试登录
- 点击"微信一键登录"
- 截图首页

#### 3. 测试新建订单
- 点击"新建订单"
- 选择客户
- 添加商品
- 提交订单
- 截图订单详情

#### 4. 测试订单列表
- 点击底部导航"订单"
- 截图订单列表
- 点击任意订单
- 截图订单详情

#### 5. 测试商品管理
- 点击"商品管理"
- 截图商品列表
- 测试筛选、排序、导出

#### 6. 测试客户管理
- 点击"客户管理"
- 截图客户列表
- 测试搜索功能

#### 7. 测试赊销管理
- 点击底部导航"赊销"
- 截图赊销页面
- 测试收款确认

#### 8. 测试分拣出库
- 点击底部导航"分拣出库"
- 截图分拣页面

#### 9. 测试我的页面
- 点击底部导航"我的"
- 截图我的页面
- 点击"成员管理"
- 截图成员管理

#### 10. 检查控制台日志
- 微信开发者工具 → 调试器 → Console
- 检查是否有错误
- 截图保存
