# 云函数部署指南

## 必须步骤

1. **打开微信开发者工具**
2. **右键点击 `cloudfunctions` 文件夹**
3. **选择「当前环境：cloud1」**（确保环境正确）
4. **右键点击每个云函数文件夹，选择「上传并部署：云端安装依赖」**

## 需要上传的云函数列表

- [ ] auth
- [ ] products
- [ ] customers
- [ ] orders
- [ ] receivable
- [ ] outbound
- [ ] report
- [ ] users
- [ ] clear-all-data
- [ ] system

## 快速部署方法

在终端执行：
```bash
cd /Users/god/Desktop/项目/github/fenghuai-trading/cloudfunctions
for dir in */; do
  if [ -f "${dir}index.js" ]; then
    echo "准备上传：${dir}"
    cd "${dir}"
    npm install
    cd ..
  fi
done
```

然后在微信开发者工具中右键 cloudfunctions → "上传并部署：云端安装依赖（不上传 node_modules）"

## 部署后验证

1. 编译小程序
2. 进入商品管理页面
3. 应该能看到商品列表
