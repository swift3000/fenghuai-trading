### ⭐⭐⭐⭐⭐ 优先级 1：核心功能测试

#### 测试 1：新建订单 - 客户选择功能
**目的**: 验证客户选择功能是否修复

**步骤**:
1. 点击首页的 **"新建订单"** 按钮
2. 点击 **"选择客户"** 按钮
3. **预期**: 弹出客户选择窗口
4. 在搜索框输入 "万友" 或任意关键词
5. **预期**: 客户列表根据关键词过滤
6. 点击任意客户（如 "万友超市"）
7. **预期**: 
   - 弹窗关闭
   - 客户名称显示在输入框
   - 显示客户电话和区域
   - 出现 "已选择：XXX" 的提示

**控制台日志应该显示**:
```
👥 开始加载客户列表...
📦 客户列表云函数返回：{...}
✅ 客户列表加载完成：XX 个
✅ 用户点击选择客户：{name: "万友超市", ...}
✅ 客户信息已设置
```

**❌ 如果失败**:
- 弹窗不显示 → 检查 `showCustomerPicker` 数据绑定
- 点击无反应 → 检查 `selectCustomerItem` 函数
- 客户列表为空 → 检查云函数 `customers` 是否已部署

## 🔍 调试技巧

### 查看控制台日志
1. 打开微信开发者工具的 **"调试器"** 面板
2. 选择 **"Console"** 标签
3. 执行操作时观察日志输出

### 查看网络请求
1. 选择 **"Network"** 标签
2. 查看云函数调用是否成功
3. 检查返回数据格式

### 查看页面数据
在 Console 中输入：
```javascript
getApp().globalData.userInfo  // 查看当前用户
```

## 🐛 常见问题排查

### Q1: 客户选择弹窗不显示
**检查**:
- `showCustomerPicker` 是否为 `true`
- WXML 中是否有 `wx:if="{{showCustomerPicker}}"`
- 控制台是否有 JavaScript 错误

### Q2: 订单详情空白
**检查**:
- 控制台 `loadOrderDetail` 日志
- 云函数是否返回数据
- `order._id` 和 `order.items` 是否存在

### Q3: 商品列表为空
**检查**:
- 云函数 `products` 是否正常返回
- `loadProducts` 日志中的商品数量
- WXML 中商品列表的 `wx:for` 绑定

### Q4: 赊销按钮错位
**检查**:
- `receivable.wxss` 中的 `.top-actions` 样式
- 是否包含 `gap` 和 `flex-shrink` 属性
- 浏览器缩放比例（应为 100%）
