# 🚀 CloudBase CLI 自动化部署解决方案

## ❌ 问题描述

CloudBase CLI 的登录状态无法在子进程中传递，导致自动化部署失败。

**原因**：微信开发者工具的安全限制，子进程无法继承父进程的登录态。

---

## ✅ 解决方案

### 方案 1：API 密钥认证（推荐 · 最稳定）

**优点**：
- 无交互式登录，适合 CI/CD 自动化
- 登录态持久化，无需重复扫码
- 子进程可以继承登录态

**步骤**：

1. **获取腾讯云 API 密钥**
   - 访问：https://console.cloud.tencent.com/cam/capi
   - 点击 "创建密钥"
   - 记录 `SecretId` 和 `SecretKey`

2. **使用 API 密钥登录**
   ```bash
   tcb login --apiKeyId YOUR_SECRET_ID --apiKey YOUR_SECRET_KEY
   ```

3. **执行自动化部署**
   ```bash
   # 登录态会持久化，后续命令无需重复登录
   tcb db nosql execute --database-name "cloud1-d6g75loi673b1e039" --command '...'
   tcb fn deploy --all
   ```

**安全提示**：
- ⚠️ API 密钥权限较高，请妥善保管
- ⚠️ 不要将密钥提交到 Git
- ✅ 建议使用 `.env` 文件存储密钥
- ✅ 定期轮换密钥

---

### 方案 2：分步登录（适合 AI 场景）

**优点**：
- 无需 API 密钥
- 适合 AI 助手场景

**步骤**：

1. **启动登录会话**
   ```bash
   tcb login start
   ```
   输出：
   ```
   user_code: XXXX-XXXX
   verification_uri: https://tcb.cloud.tencent.com/dev#/cli-auth
   ```

2. **用户扫码授权**
   - 打开浏览器访问 verification_uri
   - 输入 user_code 并确认授权

3. **完成登录**
   ```bash
   tcb login complete --session-id SESSION_ID
   ```

**缺点**：
- 需要用户交互
- 登录态可能过期

---

### 方案 3：环境变量传递（临时方案）

**步骤**：

1. **在父进程中设置环境变量**
   ```bash
   export CLOUDBASE_ENV_ID=cloud1-d6g75loi673b1e039
   export CLOUDBASE_SECRET_ID=xxx
   export CLOUDBASE_SECRET_KEY=xxx
   ```

2. **子进程继承环境变量**
   ```javascript
   const { execSync } = require('child_process');
   const env = { ...process.env }; // 继承所有环境变量
   
   execSync('tcb db nosql execute ...', {
     env,
     stdio: 'inherit'
   });
   ```

**缺点**：
- 仍然需要初始登录
- 登录态可能过期

---

## 🎯 推荐方案

**对于本项目，推荐使用方案 1（API 密钥认证）**

**理由**：
1. 一次性配置，永久有效
2. 无需每次扫码
3. 子进程可以正常继承登录态
4. 适合自动化部署脚本

---

## 📋 实施步骤

### 1. 创建 API 密钥

访问：https://console.cloud.tencent.com/cam/capi

1. 点击 "创建密钥"
2. 选择 "子账号密钥"（更安全）
3. 授予 CloudBase 相关权限
4. 下载并保存密钥

### 2. 配置环境变量

在项目根目录创建 `.env` 文件：

```bash
# .env（不要提交到 Git）
CLOUDBASE_SECRET_ID=AKIDxxxxxxxxxxxxxxxxxxxxxxxxxxxx
CLOUDBASE_SECRET_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
CLOUDBASE_ENV_ID=cloud1-d6g75loi673b1e039
```

### 3. 修改部署脚本

在部署脚本中添加：

```bash
#!/bin/bash

# 加载环境变量
if [ -f .env ]; then
  export $(cat .env | grep -v '^#' | xargs)
fi

# 使用 API 密钥登录（如果未登录）
if ! tcb login --status 2>&1 | grep -q "succeeded"; then
  echo "🔑 使用 API 密钥登录..."
  tcb login --apiKeyId "$CLOUDBASE_SECRET_ID" --apiKey "$CLOUDBASE_SECRET_KEY"
fi

# 执行部署
echo "🚀 开始部署..."
node scripts/init-database.js
tcb fn deploy --all
```

### 4. 执行自动化部署

```bash
chmod +x scripts/deploy.sh
./scripts/deploy.sh
```

---

## 🔒 安全最佳实践

1. **不要将密钥提交到 Git**
   ```bash
   # 在 .gitignore 中添加
   .env
   *.key
   ```

2. **使用子账号密钥**
   - 不要使用主账号密钥
   - 限制子账号权限范围

3. **定期轮换密钥**
   - 建议每 3-6 个月轮换一次
   - 轮换后更新所有部署脚本

4. **监控密钥使用**
   - 在腾讯云控制台查看密钥使用日志
   - 发现异常立即撤销
