## ⚠️ 常见问题

### 1. MCP 服务启动失败

**现象：** `MCP startup failed: handshaking with MCP server failed`

**解决：**
```bash
# 停止旧服务
pkill -f wechat-devtools-mcp

# 检查配置
cat ~/.codex/config.toml | grep -A 5 wechat

# 重启 Codex
```

### 2. 云函数上传失败

**现象：** `上传失败：auth`

**可能原因：**
- 微信开发者工具未登录
- 云环境未配置
- 权限不足

**解决：**
```bash
# 手动打开开发者工具登录
open -a wechatwebdevtools

# 检查云环境配置
cat cloudfunctions/config.json
```

### 3. TabBar 设置失败

**现象：** `TabBar 设置失败：{}`

**解决：**
- 检查 `app.json` 中 TabBar 配置
- 确认图标文件存在
- 检查角色权限配置
