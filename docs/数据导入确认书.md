## 六、风险规避

### ✅ 已解决的问题

1. ~~价格字段歧义~~ → 已统一为 `price_unit`
2. ~~数据导入不完整~~ → 已支持批量导入 + 进度提示
3. ~~重复数据问题~~ → 导入前自动清空
4. ~~字段映射错误~~ → 已验证字段一一对应

### ⚠️ 注意事项

1. **导入前备份**: 如需保留现有数据，请先导出备份
2. **覆盖确认**: 导入时会提示是否覆盖，请谨慎选择
3. **网络稳定**: 导入过程中保持网络稳定
4. **不要重复导入**: 同一数据多次导入会产生重复（已做防重处理）
