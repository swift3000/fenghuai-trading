## 五、数据流转检查

### ✅ 5.1 商品数据流转

```
商品管理 (CRUD) 
    ↓ 保存到云数据库 products 集合
    ↓ 调用云函数 products/list
新建订单 → 加载商品列表 → 显示名称/料号/规格/价格
    ↓ 选择商品
添加到订单明细 → 带上次价格 → 可修改 → 保存订单
```

### ✅ 5.2 客户数据流转

```
客户管理 (CRUD)
    ↓ 保存到云数据库 customers 集合
    ↓ 调用云函数 customers/list
新建订单 → 加载客户列表 → 显示名称/区域/联系人/电话
    ↓ 选择客户
带出上次订单价格 → 添加到商品时带价 → 保存订单
```

### ✅ 5.3 订单数据流转

```
新建订单
    ↓ 填写客户 + 商品明细 + 数量 + 价格
    ↓ 校验 (客户必填 + 商品必填 + 金额>0)
    ↓ 调用云函数 orders/create
云数据库 orders 集合 → 生成订单号 → 状态=submitted
```
