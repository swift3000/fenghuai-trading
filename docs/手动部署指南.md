## 🔍 常见问题

### Q1: 云函数上传失败
**解决**：
1. 检查网络连接
2. 右键云函数 → "删除云函数"
3. 重新上传

### Q2: 数据库集合创建失败
**解决**：
1. 检查集合名称是否正确（小写，下划线分隔）
2. 确认云开发环境已开通

### Q3: 登录时提示"云函数不存在"
**解决**：
1. 确认 auth 云函数已上传
2. 检查 app.js 中的环境 ID 是否正确
