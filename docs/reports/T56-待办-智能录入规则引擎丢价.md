# T56 任务卡：智能录入规则引擎丢价（SA-1 复测确认）

状态：进行中

来源：graph 测试 A 路报 SA-1（P1，智能录入丢价无法建单）；2026-08-30 用户指令"再跑一遍再测一遍，修复哪个问题就修哪个"后复测定位。

## 根因（复测三层排除法定位）
- 商品原件层：167/167 商品均有 price_piece/material_code（老酸奶 piece=45），排除。
- 金额算法层：orders 服务端重算 T51-2 正确，排除。
- **代码层（根因）**：smart 云函数规则引擎（parseOrderText/parseMultiProductText）返回 item 仅 {_id,name,spec,price,qty}，缺 material_code/pricing_mode/price_unit/unit；前端 parseOnline 用 `if (it.material_code)` 判"已匹配商品"，规则命中项无 material_code → 落"未匹配自由项"分支 price 置 0 → 总额 0 → 建单被"订单金额为 0"拦截。仅 AI 路径（buildItems）字段齐全。规则引擎是主路径（AI 为可选兜底），故普通文字录入必踩。

## 修复方案
smart 云函数新增 normalizeRuleItems(items, products)：按 _id 回查商品库补 material_code/pricing_mode/price_unit/unit（缺省 unit='包'，与 AI 路径 buildItems 同口径）；parse 与 parseWithAI 两处返回前归一化。纯增字段，不破坏 AI 路径（已有字段不覆盖）。
