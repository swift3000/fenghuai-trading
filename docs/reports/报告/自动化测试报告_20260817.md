### 自动化踩坑（已解决，供后续参考）
1. **App 启动自动跳转抢跑**：`app.js onLaunch` 检测已登录就 `reLaunch(/pages/index/index)`，冷启动时原生 reLaunch 到目标页会被盖回首页。解决：先让 App 落首页，再用**页面内 `wx.reLaunch`** 切页。
2. **DevTools 单实例限制**：GUI 开发者工具与 headless 自动化抢同一 user-data-dir → `getPageMetaByWebviewId null` / 卡死。解决：自动化前 `pkill` 关掉 GUI 实例，只留一个。
3. **stale 锁**：`wechat-devtools-automator.lock` 无 stale 检测，进程被杀后残留锁阻塞后续运行。解决：校验锁内 pid 已死后删除。
4. **headless 无登录态**：全新实例 storage 空会停登录页。解决：`wx.setStorageSync('userInfo', admin)` 注入 + 设置 `getApp().globalData`。
