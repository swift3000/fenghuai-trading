## ✅ 下一步行动

### 必须执行（手动）
1. **在微信开发者工具中编译项目**
   - 点击"编译"按钮
   - 检查控制台是否有错误

2. **上传云函数到云端**
   - 右键 `cloudfunctions` 文件夹
   - 选择"上传并部署：云端安装依赖"
   - 等待所有云函数部署完成

3. **初始化数据库**
   - 右键 `cloudfunctions/init-db`
   - 选择"运行"
   - 运行参数：`{}`
   - 确认创建了 5 个集合：users, orders, products, customers, receivable

4. **测试登录**
   - 点击"微信一键登录"
   - 确认登录成功并跳转到首页

5. **测试核心流程**
   - 新建订单 → 选择客户 → 添加商品 → 提交
   - 查看订单列表 → 点击订单查看详情
   - 商品管理 → 添加/编辑/删除商品
   - 客户管理 → 添加/编辑/删除/搜索客户
   - 赊销管理 → 查看台账 → 登记收款 → 导出
   - 分拣出库 → 分拣 → 出库确认

### 对比原型检查
1. 打开 `原型/丰淮商贸采购下单助手_原型.html`
2. 逐页对比 UI 和功能
3. 记录差异并修复
