### 1. 🔴 登录失败
**现象**: 点击"微信一键登录"后提示"登录失败，请重试"

**可能原因**:
- 云函数 `auth` 未正确部署
- 云环境配置错误
- 数据库集合 `users` 不存在

**修复步骤**:
1. 检查云函数是否已上传
2. 检查云环境 ID 是否正确
3. 手动创建 `users` 集合

### 2. 🔴 订单详情空白
**现象**: 点击订单后页面空白

**可能原因**:
- `loadOrderDetail` 方法未正确调用
- 云函数 `orders` 返回数据格式错误
- 订单 ID 未正确传递

**修复步骤**:
1. 修复 `onLoad` 方法中的变量引用错误
2. 检查云函数返回数据格式
3. 添加错误处理和日志

**修复步骤**:
