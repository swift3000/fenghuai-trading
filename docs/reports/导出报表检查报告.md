## 二、导出报表结构

### 2.1 CSV 文件结构

```csv
丰淮商贸赊销报表
导出时间：2026-08-13 10:30:00
视图：客户台账 · 周期：全部

汇总：应收=10000.00 | 已收=3000.00 | 未结清=7000.00

客户，区域，订单数，应收 (¥),已收 (¥),未结清 (¥),收款状态
0088,付家河，2,1000.00,500.00,500.00,
  └ 丰淮商贸-20260813-0001,,,"500.00","500.00","0.00",待确认
  └ 丰淮商贸-20260812-0005,,,"500.00","0.00","500.00",未收款
...

合计，,10,10000.00,3000.00,7000.00,
```

### 2.2 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 客户 | 客户名称 | 0088 |
| 区域 | 客户区域 | 付家河 |
| 订单数 | 该客户订单数量 | 2 |
| 应收 (¥) | 订单总金额 | 1000.00 |
| 已收 (¥) | 已确认收款金额 | 500.00 |
| 未结清 (¥) | 剩余欠款 | 500.00 |
| **收款状态** | **订单收款状态** | **待确认/未收款/已收款** |

### 2.3 收款状态映射

| 状态值 | 显示文案 | 说明 |
|--------|---------|------|
| `unpaid` | 未收款 | 无任何收款记录 |
| `pending` | 待确认 | 已登记收款，待库管确认 |
| `paid` | 已收款 | 已全额结清 |

## 三、导出功能特性

### 3.1 支持的功能

| 功能 | 状态 | 说明 |
|------|------|------|
| **周期筛选导出** | ✅ | 全部/今日/本周/本月/自定义 |
| **视图筛选导出** | ✅ | 客户台账/未结清/已结清 |
| **搜索筛选导出** | ✅ | 按客户名/区域搜索 |
| **客户汇总** | ✅ | 客户维度的应收/已收/未结清 |
| **订单明细** | ✅ | 每个客户的订单明细展开 |
| **收款状态** | ✅ | 显示每笔订单的收款状态 |
| **合计行** | ✅ | 总计应收/已收/未结清 |
| **CSV 格式** | ✅ | 标准 CSV，支持 Excel 打开 |
| **文件命名** | ✅ | 丰淮商贸赊销报表_YYYY-MM-DD.csv |
| **保存位置** | ✅ | wx.env.USER_DATA_PATH |

### 3.2 导出流程

```
1. 进入赊销页面
2. 选择视图（台账/未结清/已结清）
3. 选择周期（全部/今日/本周/本月/自定义）
4. 可选：输入搜索关键词
5. 点击"📥 导出"按钮
6. 生成 CSV 文件
7. 显示保存路径
8. 可通过文件管理工具获取
```
