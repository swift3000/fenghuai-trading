## 🎯 自动化部署方案

由于微信开发者工具 CLI 的限制，完全自动化部署需要通过以下步骤：

### 方案 A：使用 CLI 命令（推荐）

创建并执行以下脚本：

```bash
#!/bin/bash
# 文件名：full-auto-deploy.sh

PROJECT="/Users/god/Desktop/项目/github/fenghuai-trading"
ENV="cloud1-d6g75loi673b1e039"
CLI="/Applications/wechatwebdevtools.app/Contents/MacOS/cli"

echo "=========================================="
echo "  全自动部署与初始化"
echo "=========================================="

# 1. 部署所有云函数
echo ""
echo "📦 步骤 1: 部署所有云函数"
echo "-------------------"
CLOUDFUNCS="auth check-customer-fields clear-all-data customers import-data init-db orders outbound products receivable regions report smart system users"

for cf in $CLOUDFUNCS; do
  echo "  部署：$cf"
  $CLI cloud functions deploy --project "$PROJECT" --env "$ENV" "$cf" > /dev/null 2>&1 &
done

# 等待所有部署完成
echo "  等待部署完成（约 30-60 秒）..."
sleep 60

echo "✅ 云函数部署完成！"

# 2. 初始化数据库
echo ""
echo "🗄️  步骤 2: 初始化数据库"
echo "-------------------"
echo "  运行 init-db 云函数..."
# 注意：CLI 无法直接运行云函数，需要在 IDE 中手动执行

echo "⚠️  请在微信开发者工具中："
echo "  1. 右键 cloudfunctions/init-db"
echo "  2. 选择'运行测试'"
echo "  3. 输入参数：{}"
echo "  4. 点击'运行测试'"

# 3. 导入数据
echo ""
echo "📥 步骤 3: 导入默认数据"
echo "-------------------"
echo "⚠️  请在微信开发者工具中："
echo "  1. 右键 cloudfunctions/import-data"
echo "  2. 选择'运行测试'"
echo "  3. 输入参数：{\"action\": \"import-all\"}"
echo "  4. 点击'运行测试'"

echo ""
echo "=========================================="
echo "  部署与初始化完成！"
echo "=========================================="
echo ""
echo "📱 下一步：在微信开发者工具中点击'编译'，然后测试小程序"
```

### 方案 B：在微信开发者工具中手动执行（最简单）

1. **上传所有云函数**：
   - 右键 `cloudfunctions` 文件夹
   - 选择"上传并部署：云端安装依赖（不上传 node_modules）"
   - 等待所有云函数上传完成

2. **初始化数据库**：
   - 右键 `cloudfunctions/init-db`
   - 选择"运行测试"
   - 输入参数：`{}`
   - 点击"运行测试"

3. **导入默认数据**：
   - 右键 `cloudfunctions/import-data`
   - 选择"运行测试"
   - 输入参数：`{"action": "import-all"}`
   - 点击"运行测试"

4. **编译测试**：
   - 点击顶部"编译"按钮
   - 测试所有功能
