## ⚠️ 注意事项

1. **数据导入是破坏性操作**
   - 会清空现有客户和商品数据
   - 仅建议在首次初始化时使用
   - 已有数据时请谨慎操作

2. **管理员权限要求**
   - 数据导入需要管理员权限
   - 首次登录会自动创建管理员账号

3. **云函数部署**
   - 确保 `init-db` 和 `import-data` 云函数已上传到云端
   - 上传后才能执行初始化

## 🚀 推荐操作流程

### 首次使用（全新安装）
1. 上传所有云函数
2. 运行 `init-db` 创建集合
3. 运行 `import-data` 导入默认数据
4. 登录小程序（自动创建管理员）
5. 开始使用

### 已有数据（保留数据）
1. 上传所有云函数
2. 运行 `init-db` 确保集合存在
3. **不要**运行 `import-data`（会清空数据）
4. 直接使用现有数据

### 重置数据（清空重来）
1. 上传所有云函数
2. 运行 `init-db` 
3. 运行 `import-data` 导入默认数据
4. 重新开始
