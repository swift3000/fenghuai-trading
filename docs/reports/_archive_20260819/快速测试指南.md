# 快速测试指南

## 🚀 立即测试步骤

### 步骤 1: 上传云函数依赖

在微信开发者工具中：
1. 右键点击 `cloudfunctions` 文件夹
2. 选择 **"上传并部署：云端安装依赖"**
3. 等待上传完成

### 步骤 2: 编译小程序

1. 点击顶部工具栏的 **"编译"** 按钮
2. 等待编译完成
3. 查看模拟器是否正常显示

### 步骤 3: 测试客户选择

1. 点击 **"新建订单"** 按钮
2. 点击客户栏（显示"请选择客户"）
3. **预期结果**: 弹出客户选择窗口
4. 点击任意客户
5. **预期结果**: 客户被选中，弹窗关闭

### 步骤 4: 测试智能录入

1. 在新建订单页面，点击 **"智能录入"** 按钮
2. **预期结果**: 显示智能录入弹窗
3. 查看语音录入提示
4. **预期结果**: 显示"语音录入功能开发中"提示
5. 在文本框输入：`手抓饼 2 件，老酸奶 10 包`
6. **预期结果**: 实时显示识别结果预览
7. 点击 **"确认添加"**
8. **预期结果**: 商品添加到订单明细

### 步骤 5: 测试订单详情

1. 在订单列表页面，点击任意订单卡片
2. **预期结果**: 跳转到订单详情页面
3. 检查订单信息
4. **预期结果**: 显示客户名、订单号、金额、商品列表等

## 🐛 常见问题排查

### 问题 1: 客户选择弹窗不显示

**检查**:
```javascript
// 在控制台输入
console.log(this.data.customerList)
console.log(this.data.displayCustomers)
```

**解决**: 确保已调用 `loadCustomers()` 且客户数据已加载

### 问题 2: 订单详情页面空白

**检查**:
```javascript
// 在订单详情页面控制台输入
console.log(this.data.order)
console.log(this.data.items)
```

**解决**: 检查云函数是否返回正确数据

### 问题 3: 商品列表不显示

**检查**:
```javascript
// 在订单列表页面控制台输入
console.log(this.data.orders[0].items)
```

**解决**: 检查数据库中订单的 `items` 字段是否有数据

### 问题 4: 智能录入无法识别

**检查**:
```javascript
// 在控制台输入
console.log(this.data.productList)
```

**解决**: 确保数据库中已有商品数据
