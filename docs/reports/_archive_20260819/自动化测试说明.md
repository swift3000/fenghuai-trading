# 微信小程序自动化测试方案

## 当前状态

由于 wechat-devtools-mcp 的 MCP 工具不能直接在 shell 中调用，需要通过 Codex 的 MCP 系统调用。

## 推荐方案

### 方案 1: 使用 Computer Use 技能（推荐）

使用 Computer Use 技能直接操作微信开发者工具的 UI：

1. **打开微信开发者工具**
   - 点击 Dock 栏或应用程序文件夹中的微信开发者工具图标

2. **打开项目**
   - 文件 → 打开项目
   - 选择项目路径：`/Users/god/Desktop/项目/github/fenghuai-trading`

3. **编译项目**
   - 点击顶部工具栏的"编译"按钮

4. **自动化测试流程**
   - 登录测试
   - 新建订单测试
   - 订单列表测试
   - 商品管理测试
   - 客户管理测试
   - 赊销管理测试
   - 每个步骤截图

### 方案 2: 手动测试 + 截图

由于自动化测试需要额外的配置，建议先进行手动测试：

1. **编译项目**
   ```
   微信开发者工具 → 点击"编译"按钮
   ```

2. **测试登录**
   - 点击"微信一键登录"
   - 截图登录成功后的首页

3. **测试新建订单**
   - 点击"新建订单"按钮
   - 选择客户
   - 添加商品
   - 提交订单
   - 截图订单详情

4. **测试其他功能**
   - 订单列表
   - 商品管理
   - 客户管理
   - 赊销管理
   - 每个页面截图
