# 🔧 微信开发者工具 - 调试环境检查清单

## ❌ 常见导致"很多功能不行"的原因

### 1. 云开发环境未正确配置 ⚠️ 最可能的问题

**检查步骤**：
1. 打开微信开发者工具
2. 点击右上角 **"云开发"** 按钮
3. 检查是否显示云环境 ID（如 `cloud1`）
4. 如果显示"未开通云开发"或环境列表为空 → **问题根源！**

**解决方案**：
- 如果未开通云开发：点击"开通云开发" → 选择"免费版" → 创建环境
- 如果环境存在但没显示：工具 → 设置 → 云开发 → 选择正确的环境

---

### 2. AppID 问题

**当前配置**：`wxe4ab72773abd200f`

**检查**：
- 这是正式 AppID 还是测试号？
- 如果是测试号，某些功能可能受限

**解决方案**：
- 如果有正式 AppID：修改 `project.config.json` 中的 `appid`
- 如果没有：保持测试号，但注意某些功能可能不完整

---

### 3. 云函数环境不匹配

**问题**：云函数上传到了错误的环境

**检查步骤**：
1. 右键 `cloudfunctions` 文件夹
2. 查看"当前环境"显示的是什么
3. 确保与云开发控制台中的环境一致

**解决方案**：
- 右键 `cloudfunctions` → 选择正确的环境
- 重新上传所有云函数

---

### 4. 基础库版本问题

**当前配置**：`3.17.1`

**检查**：
- 这个版本较新，应该没问题
- 但如果用户手机微信版本过低，可能不支持某些 API

**解决方案**：
- 在微信开发者工具中：详情 → 本地设置
- 勾选"不校验合法域名"
- 使用模拟器测试，真机调试需要较新微信版本

---

### 5. 域名校验问题

**当前配置**：`urlCheck: false` ✅ 正确

**但需要额外配置**：
1. 工具 → 设置 → 安全
2. 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"

## ✅ 正确的调试步骤

### 第一步：确认云开发环境

1. 点击右上角 **"云开发"** 按钮
2. 确保显示环境 ID（如 `cloud1`）
3. 如果没有，先开通云开发（免费版即可）

### 第二步：配置云函数环境

1. 右键 `cloudfunctions` 文件夹
2. 确认"当前环境"显示正确的环境 ID
3. 如果不对，右键 → "当前环境" → 选择正确的环境

### 第三步：重新上传所有云函数

1. 右键 `cloudfunctions` 文件夹
2. 选择 **"上传并部署：云端安装依赖（不上传 node_modules）"**
3. 等待所有云函数显示绿色 ✓

### 第四步：清除缓存并重新编译

1. 工具 → 清除缓存 → **清除全部缓存**
2. 点击 **"编译"** 按钮

### 第五步：开启详细日志

1. 点击底部 **"调试器"** 标签
2. 点击 **"Console"** 子标签
3. 清空之前的日志
4. 执行操作，观察 Console 输出
