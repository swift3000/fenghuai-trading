# 🛠️ 自动化测试工具使用指南

## 🚀 快速开始

### 1. 一键诊断（推荐首次使用）

```bash
./tests/diagnose.sh
```

**检查内容：**
- ✅ 环境配置
- ✅ 工具安装
- ✅ 脚本完整性
- ✅ 代码质量
- ✅ 云函数配置

---

### 2. 运行完整测试

```bash
./tests/run-full-automation.sh
```

**执行流程：**
1. 环境检查
2. 单元测试
3. UI 自动化测试
4. 云函数状态检查
5. 自动上传（测试通过后）
6. 生成报告

---

### 3. 查看报告

测试完成后，报告位于：
```
reports/
├── test-report-YYYY-MM-DD-HH-MM-SS.json
├── test-report-YYYY-MM-DD-HH-MM-SS.md
└── test-report-YYYY-MM-DD-HH-MM-SS.html
```

**HTML 报告可直接在浏览器打开查看**

## 📋 常用命令

### 测试相关

| 命令 | 说明 |
|------|------|
| `./tests/diagnose.sh` | 一键诊断所有问题 |
| `./tests/run-full-automation.sh` | 运行完整测试流程 |
| `node tests/integrated-test.js` | 仅运行集成测试 |
| `node tests/auto-test.js` | 仅运行单元测试 |
| `node tests/complete-ui-test.js` | 仅运行 UI 测试 |

### 云函数相关

| 命令 | 说明 |
|------|------|
| `node tests/upload-cloudfunctions.js create-config` | 创建缺失的配置 |
| `node tests/upload-cloudfunctions.js upload-all` | 上传所有云函数 |
| `node tests/upload-cloudfunctions.js check-deployed` | 检查部署状态 |

### 配置管理

| 命令 | 说明 |
|------|------|
| `node tests/config-manager.js init` | 初始化配置 |
| `node tests/config-manager.js list` | 查看所有配置 |
| `node tests/config-manager.js get test.timeout` | 获取特定配置 |
| `node tests/config-manager.js set test.timeout 60000` | 修改配置 |
| `node tests/config-manager.js reset` | 重置配置 |

## ⚙️ 配置说明

### 配置文件位置
```
test-config.json
```

### 主要配置项

```json
{
  "test": {
    "skipPages": [],        // 跳过的页面
    "timeout": 30000,       // 超时时间（毫秒）
    "retryCount": 2,        // 重试次数
    "screenshotOnFailure": true,  // 失败时截图
    "logLevel": "info"      // 日志级别
  },
  "cloudfunctions": {
    "autoUpload": false,    // 自动上传
    "uploadAfterTest": true,    // 测试后上传
    "env": "auto-configured",   // 云环境
    "timeout": 5,           // 函数超时（秒）
    "memory": 1024          // 函数内存（MB）
  },
  "mcp": {
    "enabled": true,        // 启用 MCP
    "autoStart": true,      // 自动启动
    "timeout": 30           // MCP 超时（秒）
  }
}
```

## 🔧 故障排查

### 问题 1: MCP 服务启动失败

**症状**: `MCP startup failed`

**解决**:
```bash
# 停止旧服务
pkill -f wechat-devtools-mcp

# 检查配置
cat ~/.codex/config.toml | grep -A 5 wechat

# 重新运行测试
./tests/run-full-automation.sh
```

---

### 问题 2: 云函数上传失败

**症状**: `上传失败: xxx`

**解决**:
```bash
# 1. 创建缺失的配置
node tests/upload-cloudfunctions.js create-config

# 2. 手动在微信开发者工具中上传
# 打开工具 -> 右键 cloudfunctions -> 上传并部署

# 3. 或尝试 CLI 上传
node tests/upload-cloudfunctions.js upload-all
```

---

### 问题 3: 页面测试失败

**症状**: `Page is not defined` 或 `getApp is not defined`

**解决**:
```bash
# 运行诊断查看具体问题
./tests/diagnose.sh

# 修复示例：在 pages/xxx/xxx.js 顶部添加
const app = getApp()
```

## 📈 性能优化

### 1. 并行测试
```bash
# 同时测试多个页面（需修改脚本）
node tests/integrated-test.js --parallel
```

### 2. 跳过已通过的测试
```bash
# 配置中设置
node tests/config-manager.js set test.skipPassed true
```

### 3. 减少截图
```bash
# 仅在失败时截图（默认）
node tests/config-manager.js set test.screenshotOnFailure true
```
