- 现象 A：云函数生产依赖 11 个 high/critical（wx-server-sdk 链：axios/jsonwebtoken/protobufjs/form-data/request；xlsx ^0.18.5 prototype pollution + ReDoS，位于 Excel 导出热路径）。上游无可用修复版本。
- 豁免理由：
  1. wx-server-sdk 为微信云开发官方 SDK，版本受平台约束不可自选，漏洞均在传递依赖且无直接网络暴露面（云函数入参已校验）；
  2. xlsx 0.18.5 为 SheetJS 最后发布的 npm 版本（新版转 cdn.sheetjs.com 分发），npm 源无修复版本；
  3. miniprogram-ci 根目录 76 项全为 CI 构建工具链（babel 旧链），不随产品上线。
- 复核条件：wx-server-sdk 或 xlsx 发布含安全修复的新版本时销本豁免并升级。
- 现象 B：smart/outbound/auth/users/system/regions 6 个云函数缺 package-lock.json（违反 lockfile 必入库纪律）
- 做法：B 用 npm install --package-lock-only 生成 lockfile 后入库（不装 node_modules、不动运行态）；A 以本豁免段登记
- 验收：6 个目录均有 package-lock.json 且 git 已跟踪；package.json 版本零改动（diff 验证）
