# T41 语音/文字智能录入方言适配

状态：已做（2026-08-24 销项，全量回归 11 步全绿）

## 背景
用户反馈：语音功能"没开盘"（实际已开发），需"赶快把没干的全做完"，且用户群体本地方言多、口述内容简单。经盘点语音链路（ASR 转写 + 规则引擎 + AI 降级）已完整，真实缺口=规则引擎与 AI 提示词不做方言容错。

## 改动（cloudfunctions/smart/index.js，纯本地规则引擎 + 提示词）
1. **中文数字量词**：cnNumToInt 支持 一~九/两/十/十几/几十几；extractQuantity 优先"数字+量词紧邻"
2. **同音字归一**：HOMO_MAP 仅"罕见 ASR 错字→商品标准字"单向（魔→馍、角→饺、脚→饺、代→袋、常→肠…），标准字不反向，防误伤真实商品名
3. **整句无空格滑窗**：matchProductInSegment 同音归一精确/模糊 + 最长子串兜底；商品名片段防误命中（400克晶纯盐 的 晶纯盐 不当独立商品）
4. **一行多商品**：parseMultiProductText 全商品定位 + 量词"商品后优先、就近"贪心配对（商品前紧邻量词如"两个白吉馍"也识别）
5. **商品名内数字防护**：主正则命中数字前 8 字含商品名片段则跳过（400克晶纯盐 的 400 不当数量）
6. **AI 提示词**：parseWithAI/parseWithTokenhub 统一走 dialectParseSystem，增加"本地方言+同音字"说明
