**6. 订单金额类型缺陷（totalAmount 字符串拼接）**
- 前端 `new-order` 保存时 `totalAmount: pricing.fmtMoney(total)` 传的是 `.toFixed(2)` 字符串（如 `"123.45"`）；云函数 `orders` `create/update` 原样入库，导致 `todayStats` 的 `amount += o.totalAmount` 触发**字符串拼接**而非数值累加，金额失真，且 `<=0` 判断依赖隐式转换不稳。已修：云函数统一 `Number(event.totalAmount)||0` 入库，`todayStats` 改 `Number(o.totalAmount)`。`node --check` 通过、测试 59/59 保持。

**7. 订单删除残留孤儿收款记录**
- `orders` 云函数 `delete` 仅 `remove()` 订单本身，不清理关联 `payments`。后果：删除订单后其 `status='pending'` 收款单仍留在库管「待确认收款」工作台，点确认时因订单不存在报错，形成孤儿数据。已修：`delete` 时按 `orderId` 级联删除该订单全部收款记录。`node --check` 通过、测试 59/59 保持。

**8. 权限开关对老用户不生效（全链路）**
- 管理员在成员管理改权限开关，仅写入 `perm_configs`；而业务云函数 `checkPermission` 与前端门禁都读 `users.permissions`。老用户登录时**仅在 permissions 为空才同步**，故已存在用户的权限不随开关刷新，权限控制形同失效。已修：`auth` `login` 老用户分支每次登录都对覆盖后权限做对比并在变化时同步到 `users.permissions`，打通「perm_configs → login 同步 → users.permissions → 业务校验」全链路。`node --check` 通过、测试 59/59 保持。

**9. 订单未持久化客户区域（customerRegion）**
- 订单 `create/update` 未存储 `customerRegion`，但订单列表客户分组（`orders.js`）与出库导出（`orders.js` exportOutbound）都读取它 → 分组区域恒空、出库单区域空白。已修：`orders` 云函数 `create/update` 持久化 `customerRegion`，前端 `new-order` 保存 payload 带 `customerRegion: this.data.customer.region`。`node --check` 通过、测试 59/59 保持。

## 三C、Loop 循环核验（2026-08-13 晚）· 前后端返回契约一致性逐项排查（测试驱动）

在 50/50 基线上继续「按 loop 来，参照原型」逐项对比原型，重点扫描**所有 callCloud 调用的返回结构 vs 前端读取路径**，修复 5 项固有问题并新增回归用例，基线升至 **59/59**：

**1. 待确认收款工作台恒空（前后端契约）**
- `cloudfunctions/receivable/index.js` `pendingConfirm` 返回 `data: payments`(数组)；前端 `res.data || []` 读取（callCloud 已解包 → undefined）→ 工作台恒空。已修前端直接取 `res`（数组）。

**2. 导入原型数据前后端契约不匹配**
- 前端 `confirmImport` 传 `{type,data,override}` 并读 `result.code/success/failed`；云函数 `import-data` 只认 `action` 且返回 `success/successCount/failCount`，无 code → 导入恒失败「未知操作」。已修前端按 action 契约调用并读取真实字段。

**3. 报表明细恒空/恒显示暂无数据（契约）**
- `reports.js` `setData({...data})` 把 `products/customers/methods` 展开到顶层，但 WXML 读 `data.products`（page.data.data.xxx），`data` 仍为初始数组 → 明细恒空、`data.length===0` 恒真。已修 JS 同时把 `data` 设为 summary 对象并新增 `hasData`，WXML 空态/导出改用 `hasData`。

**4. 导出功能不可用（契约）**
