# 丰淮商贸小程序 - 设计与原型对比报告

## 📋 总体评估

经过全面对比，小程序整体设计与原型文档**基本一致**。早期发现的关键差异（登录页、首页标题等）多已随迭代对齐；少数导航结构与新增系统配置页属当前实现演进，其余如下备查。

---

## ❌ 主要不一致项

### 1. 登录页面 - 已收口（移除演示残留，统一为产品真实形态 ✅）

> **收口结论（2026-08-12）**：早期原型用「4 角色卡片直选 + 示例姓名（张经理/周分拣/李库管/王老板）」演示多角色切换，这是**纯演示残留**。真实产品以微信 **openid 为唯一身份**，角色由后端决定（首管理员零配置自动 become admin，其余成员由管理员在「成员管理」分配），**登录页无角色自选**。据此已将小程序登录页统一为产品形态；原型中的角色卡片保留仅作演示展示，不代表产品登录交互。

| 设计项 | 原型（演示版） | 小程序产品版 | 一致说明 |
|--------|--------------|-------------|---------|
| **角色选择方式** | 4 个角色卡片直选 | **无自选**：openid 绑定身份，角色由后端/管理员决定 | ⚠️ 有意差异（原型为演示多角色，产品不公开自选） |
| **登录方式** | 微信一键登录 | 微信一键登录（对接 auth 云函数取真实 openid） | ✅ 一致 |
| **角色展示** | 登录时显示示例姓名（张经理等） | 不显示示例姓名，登录后按实际账号身份展示 | ✅ 产品形态 |
| **首次管理员提示** | 显示"首次启动：您将成为首位管理员"横幅 | 保留首次管理员横幅 + 登录后 Toast | ✅ 一致 |
| **品牌展示** | Logo + "丰淮商贸" + "让采购更简单" | Logo + "丰淮商贸" + "让采购更简单" | ✅ 一致 |

**小程序产品版登录页设计**：

```
│  [微信一键登录]          │

```

> 角色分配链路：**首管理员**（系统无 admin 时第一位登录者无条件设为 admin）→ 管理员在「成员管理」邀请/分配角色 → `auth/activateByInvite` 绑定 openid 激活。登录页本身不承担角色选择职责。
