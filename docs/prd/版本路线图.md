## 四、遗留观察项（不阻塞，已登记）

- **语音录入真机验证**（T45 尾项）：用户侧在微信公众平台配置「用户隐私保护指引-麦克风」后真机验语音录入——等用户操作，代码侧无需改动
- **云函数冷启动**（SB-1）：首轮 P95≈2.3s，预热后 350-1750ms 达标；业务量增长后评估预留实例
- **git tag 补打**：CHANGELOG 已到 1.7.0 但 tag 停在 v1.0.1——下次发版时补打 tag v1.7.0 对齐（发版=tag+push+部署三者一致纪律）

## 五、维护规则

- 每次发版（次版本/修订）更新 §二 轨迹表与 §一 当前状态
- 独立升级模块确认排期后，从 §三 移入排期并新建任务卡
- 观察项销项时从 §四 删除并在 CHANGELOG 留痕
