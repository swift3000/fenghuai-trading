## 🔍 问题发现

在深度检查原型时发现：
- **PRD 要求**: 
  > 点【发送给客户微信】→ 标记订单 `shared_to_wechat=true` + `shared_at`，Toast「已转发至客户微信」；订单详情「微信转发」行显示已转发时间。
- **当前实现**: 
  - ✅ 有转发按钮（`open-type="share"`）
  - ❌ **没有记录转发状态**（缺少数据库字段和更新逻辑）
  - ❌ **没有显示转发状态**（订单详情页无"已转发/未转发"提示）
- **原型 UI**: 
  - `id="detailWechatShared"` 显示"✓ 已转发 [时间]"或"未转发"

## ✅ 修复内容

### 1. 后端云函数修复

**文件**: `cloudfunctions/orders/index.js`

**新增动作**:
```javascript
case 'markShared': {
  // 标记订单已转发到微信
  const { orderId } = event
  await db.collection('orders').doc(orderId).update({
    data: {
      shared_to_wechat: true,
      shared_at: db.serverDate()
    }
  })
  return { code: 0, data: {} }
}
```

**功能**:
- ✅ 接收 `orderId` 参数
- ✅ 设置 `shared_to_wechat = true`
- ✅ 记录 `shared_at` 为服务器时间

### 2. 前端转发逻辑修复

**文件**: `pages/order-detail/order-detail.js`

**修改内容**:
```javascript
onShareAppMessage() {
  const order = this.data.order || {}
  const orderId = order._id || order.id
  
  // 记录转发状态
  if (orderId) {
    const { callCloud } = require('../../utils/request')
    callCloud('orders', { 
      action: 'markShared', 
      orderId: orderId 
    }).catch(e => console.error('记录转发状态失败', e))
  }
  
  return {
    title: `丰淮商贸订单 ${order.orderNo || ''} · ¥${order.totalAmount || ''}`,
    path: orderId ? `/pages/order-detail/order-detail?id=${orderId}` : '/pages/orders/orders'
  }
}
```

**功能**:
- ✅ 转发时自动调用 `markShared` 接口
- ✅ 异步记录，不影响用户体验
- ✅ 错误不影响转发功能
