## 测试步骤

### 1. 在微信开发者工具中编译小程序

```
工具 → 清除缓存 → 清除全部缓存
点击编译按钮
```

### 2. 测试商品管理

1. 进入"商品管理"页面
2. 验证：应该显示 167 个商品

   - 名称
   - 料号
   - 规格
   - 价格（件价/包价）
   - 单位（件/包）
   - 计价模式（按件销售/按个销售）

### 3. 测试客户管理

1. 进入"客户管理"页面
2. 验证：应该显示 282 个客户
3. 检查字段：
   - 客户名称
   - 别名
   - 简称
   - 联系人
   - 电话
   - 区域

### 4. 测试新建订单（核心测试）

#### 4.1 选择客户
1. 进入"新建订单"页面
2. 点击"点击选择客户"
3. 验证：弹出客户选择模态框
4. 搜索客户：输入"0088"或"0156"
5. 选择一个客户
6. 验证：客户名称显示在顶部

#### 4.2 添加商品（手动方式）
1. 点击"+ 添加商品"
2. 验证：弹出商品选择模态框
3. 搜索商品：输入"海藻"或"感冒"
4. 选择一个商品
5. 验证：
   - 商品添加到列表中
   - 价格根据计价模式自动选择
   - 总额自动计算

#### 4.3 添加商品（智能录入方式）
1. 点击"🗑 智能录入"
2. 输入格式：
   ```
   海藻碘 2 件
   感冒灵 5 包
   ```
3. 验证：
   - 显示识别预览
   - 点击"确认添加"
   - 商品添加到列表

#### 4.4 调整商品
1. 修改商品数量
2. 验证：总额自动更新
3. 删除商品
4. 验证：商品从列表移除

#### 4.5 保存订单
1. 验证总额正确
2. 点击"保存订单"
3. 验证：
   - 提示"订单已创建"
   - 返回订单列表页
   - 能看到新创建的订单

### 5. 验证订单数据

## 常见问题排查

### 问题 1：商品/客户列表为空

**原因**: 权限校验失败

**解决**:
1. 打开 vConsole
2. 查看 Network 标签
3. 检查云函数返回的 code
4. 如果返回 401，检查 users 表是否有数据

### 问题 2：价格显示错误

**原因**: 计价模式与价格字段不匹配

**解决**:
1. 检查商品数据库字段：
   - `pricing_mode`: 'case' 或 'piece'
   - `price_piece`: 件价
   - `price_unit`: 包价
2. 检查前端代码：
   - `pricing_mode === 'case'` → 使用 `price_unit`
   - `pricing_mode === 'piece'` → 使用 `price_piece`

### 问题 3：智能录入无法识别商品

**原因**: 商品名称匹配失败

**解决**:
1. 输入格式必须包含数量单位：
   - ✅ "海藻碘 2 件"
   - ❌ "海藻碘 2"
2. 商品名称必须与数据库中的名称部分匹配
