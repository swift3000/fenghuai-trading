# 数据导入指南

## 方式一：在小程序中点击导入按钮（推荐）

### 导入商品数据（180 个）
1. 打开微信开发者工具
2. 在小程序中打开 **商品管理** 页面
3. 点击右上角的 **"导入原型数据"** 按钮
4. 勾选"覆盖已存在的记录"（可选）
5. 点击 **"确认导入"**
6. 等待导入完成，会显示成功/失败数量

### 导入客户数据（284 个）
1. 在小程序中打开 **客户管理** 页面
2. 点击右上角的 **"导入原型数据"** 按钮
3. 勾选"覆盖已存在的记录"（可选）
4. 点击 **"确认导入"**
5. 等待导入完成，会显示成功/失败数量

---

## 方式二：通过云开发控制台导入

### 导入商品数据
1. 登录 [微信云开发控制台](https://console.cloud.weixin.qq.com)
2. 选择环境 `cloud1-d6g75loi673b1e039`
3. 进入 **数据库** → **products** 集合
4. 点击 **导入数据**
5. 上传 `scripts/products-data.json` 文件

### 导入客户数据
1. 进入 **数据库** → **customers** 集合
2. 点击 **导入数据**
3. 上传 `scripts/customers-all.json` 文件

---

## 数据概览

### 商品数据（180 个）
- 包含字段：material_code, name, spec, pricing_mode, unit_piece_qty, price_piece, price_unit, unit, pinyin, is_adjustable
- 示例：海藻碘、淮盐 400g、淮盐 500g 等

### 客户数据（284 个）
- 包含字段：name, alias, region, phone, contact
- 示例：0088（付家河）、1066（石泉）、万友（汉阴）等

---

## 注意事项

1. **首次导入**：数据会全部新增到数据库
2. **重复导入**：如果不勾选"覆盖"，已存在的记录不会重复插入
3. **覆盖导入**：勾选"覆盖"后，已存在的记录会被更新
4. **导入速度**：180 个商品或 284 个客户大约需要 10-20 秒
