## 🚀 立即操作步骤（必须！）

### 步骤 1：开启服务端口

在**微信开发者工具**中：
1. 点击右上角 **"设置"**
2. 选择 **"安全设置"**
3. **开启** "服务端口"

### 步骤 2：上传云函数依赖（最关键！）

1. 在微信开发者工具左侧文件树中：
   - **右键点击** `cloudfunctions` 文件夹
   - 选择 **"当前环境：cloud1"**（确认环境正确）

2. **逐个上传所有云函数**：
   - 右键 `auth` → "上传并部署：云端安装依赖"
   - 右键 `orders` → "上传并部署：云端安装依赖"
   - 右键 `products` → "上传并部署：云端安装依赖"
   - 右键 `customers` → "上传并部署：云端安装依赖"
   - 右键 `users` → "上传并部署：云端安装依赖"
   - 右键 `receivable` → "上传并部署：云端安装依赖"
   - 右键 `regions` → "上传并部署：云端安装依赖"
   - 右键 `system` → "上传并部署：云端安装依赖"
   - 右键 `reports` → "上传并部署：云端安装依赖"
   - 右键 `outbound` → "上传并部署：云端安装依赖"
   - 右键 `check-customer-fields` → "上传并部署：云端安装依赖"
   - 右键 `clear-all-data` → "上传并部署：云端安装依赖"
   - 右键 `import-data` → "上传并部署：云端安装依赖"
   - 右键 `smart` → "上传并部署：云端安装依赖"

3. **等待每个云函数上传完成**（看到"上传成功"提示）

### 步骤 3：编译小程序

点击顶部工具栏的 **"编译"** 按钮

### 步骤 4：测试登录

1. 点击 **"微信一键登录"**
2. 首次登录会自动成为管理员
3. 应该跳转到首页
