## ⚠️ 云端部署状态

**无法通过命令行检查云端状态，需要在微信开发者工具中确认**

### 如何检查是否已部署：

1. **打开微信开发者工具**
2. **查看云开发控制台**：
   - 点击顶部"云开发"按钮
   - 进入"云函数"页面
   - 查看列表中是否有以上 15 个云函数

3. **或者右键 cloudfunctions 文件夹**：
   - 如果看到"上传并部署：云端安装依赖"选项
   - 说明云函数**尚未部署**或**需要重新部署**

---

## 🎯 部署状态判断

### 如果云函数**未部署**：
你需要执行以下操作：

1. **上传所有云函数**：
   ```
   右键 cloudfunctions 文件夹
   → 选择"上传并部署：云端安装依赖（不上传 node_modules）"
   → 等待所有云函数上传完成
   ```

2. **初始化数据库**：
   ```
   右键 cloudfunctions/init-db
   → 选择"运行测试"
   → 输入参数：{}
   → 点击"运行测试"
   ```

3. **导入默认数据**（可选）：
   ```
   右键 cloudfunctions/import-data
   → 选择"运行测试"
   → 输入参数：{ "action": "import-all" }
   → 点击"运行测试"
   ```

### 如果云函数**已部署**：
直接运行 `init-db` 和 `import-data` 即可。

## 🔍 快速验证方法

在微信开发者工具中：

1. **编译小程序**（点击顶部"编译"按钮）
2. **查看控制台日志**：
   - 如果看到"云函数调用成功"
   - 说明云函数已部署且工作正常

3. **如果看到错误**：
   - "云函数不存在" → 需要上传云函数
   - "权限不足" → 检查云函数权限设置
   - "数据库集合不存在" → 运行 init-db
