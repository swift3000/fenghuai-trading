## 🔧 快速操作指南

### 上传云函数
```
1. 打开微信开发者工具
2. 右键 cloudfunctions 文件夹
3. 选择"上传并部署：云端安装依赖"
4. 等待部署完成（约 2-5 分钟）
```

### 创建数据库集合
```
1. 打开云开发控制台
2. 进入"数据库"
3. 点击"添加集合"
4. 依次创建：users, orders, products, customers, receivable
```

### 查看详细错误
```
1. 编译小程序
2. 打开调试器 → Console
3. 查看带图标的日志：
   - 📡 调用云函数：显示参数
   - ✅ 云函数成功：显示返回
   - ❌ 云函数失败：显示详细错误
```
